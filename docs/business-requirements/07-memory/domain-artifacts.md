# BP-07.4. Артефакты предметной области: память: чтение, правка, история, undo

## 1. Модель состояний памяти и факта

```
Память (папка Markdown)
 ├─ шифрование выключено → читается/правится без приложения (BR-01)
 └─ шифрование включено → только в приложении — см. BP-15 (здесь не детализируется)

Факт (одна строка с датой; Inbox / карточка / журнал проекта)
 ├─ Записан ──правка статуса──▶ Обновлён (новая версия «(статус ДД.ММ.ГГГГ)» заменяет старую)
 ├─ Записан ──новый статус────▶ Обновлён: старая версия → Факт-архив; изменение → лента событий
 ├─ Статус старше 30 дней → не подаётся как текущий; вопрос в чате при первом упоминании темы (FR-09)
 ├─ Отмена записи → «Память → История» (undo, FR-11)
 └─ Удаление факта → интерфейс + журнал — см. BP-16 (раздел 15)

Индекс: Собран ──правка источника──▶ Устарел ──автопересборка──▶ Собран (руками не правится)

Журнал: пополняется на каждую запись/чтение (со снапшотами) → основа undo и «откуда я это знаю»
```

| Переход | Откуда → куда | Правило |
|---|---|---|
| Записать факт | — → Факт записан | BP-07, шаг 2; FR-03 |
| Обновить статус | Факт записан → Обновлён | Новая версия заменяет старую — BP-07, шаг 2; FR-04 |
| Старая версия в архив | Обновлён → Факт-архив | BP-07, шаг 2; FR-04 |
| Изменение в ленту | Обновлён → Лента событий | BP-07, шаг 2; FR-04 |
| Переспрос статуса | Статус > 30 дней → вопрос в чате при первом упоминании темы | BP-07, шаг 6; FR-09; решение владельца 20.11.2026 |
| Отменить запись | Факт записан → предыдущее состояние | «Память → История» — BP-07, шаг 7; FR-11 |
| Удалить факт | Факт → удалён | Интерфейс и журнал — BP-16 (раздел 15) |
| Пересобрать индекс | Индекс устарел → собран | Правка источника — BP-07, шаг 3; FR-06 |
| Заблокировать/разблокировать | Память открыта ↔ заблокирована | BP-15 (ссылка; здесь не детализируется) |

## 2. Сущности, состояния и переходы

### 2.1 Факт

| Поле | Значение |
|---|---|
| Определение | Одна строка с датой в Inbox, карточке или журнале проекта (раздел 1) |
| Атрибуты | Текст; дата; место (Inbox / карточка / журнал проекта); источник (для «откуда я это знаю» — раздел 1) |
| Состояния | Записан → Обновлён (новый статус); Удалён (см. BP-16) |
| Переходы | Запись (FR-03); обновление статуса (FR-04); отмена через «Память → История» (FR-11); удаление — BP-16 |

### 2.2 Статус

| Поле | Значение |
|---|---|
| Определение | Версия факта вида «(статус ДД.ММ.ГГГГ)» (раздел 1) |
| Атрибуты | Текст статуса; дата ДД.ММ.ГГГГ |
| Состояния | Текущий → Заменён (старая версия уходит в факт-архив); Устаревший (старше 30 дней — переспрашивается вопросом в чате при первом упоминании темы) |
| Переходы | Новый статус заменяет старый (FR-04); переспрос при возрасте > 30 дней: вопрос в чате при первом упоминании темы (FR-09; решение владельца 20.11.2026) |

### 2.3 Факт-архив

| Поле | Значение |
|---|---|
| Определение | Хранилище старых версий статусов (раздел 1) |
| Состояния | Пополняется старыми версиями |
| Переходы | Приём старой версии при замене статуса (FR-04) |
| Правило | Факт-архив никогда не отправляется модели (FR-05; тема 4.1) |

### 2.4 Карточка темы

## 4. Правила процесса

- Факт — одна строка с датой (BP-07, шаг 2; FR-03).
- Статус — «(статус ДД.ММ.ГГГГ)»: замена версии, старая — в факт-архив, изменение — в ленту событий
  (BP-07, шаг 2; FR-04).
- Факт-архив никогда не отправляется модели (BP-07, шаг 2; FR-05; тема 4.1).
- Индекс собирается автоматически, руками не правится, пересобирается при правке источников
  (BP-07, шаг 3; FR-06).
- Статусы старше 30 дней переспрашиваются, а не подаются как текущие: вопрос в чате при первом
  упоминании темы (BP-07, шаг 6; FR-09; решение владельца 20.11.2026).
- Журнал каждого чтения/записи со снапшотами; отмена через «Память → История»; «откуда я это знаю» —
  источник факта (BP-07, шаг 7; FR-10, FR-11, FR-12).
- Экспорт журнала — Markdown/JSON, из «Память → История» (BP-16); ротация: при превышении 10 МБ архив
  с датой, хранится последних 5 (BP-07, шаг 7; FR-13; решение владельца 20.11.2026).
- Дополнительные папки — только чтение, запись блокируется; авторизация командных папок не вводится
  (BP-07, шаг 8; FR-14; решение владельца 20.11.2026).
- Достижения начисляются за события в памяти (тема 4.6; FR-15).
- Человекочитаемые коды в процессе не используются: в источниках не описаны (раздел 6 каталога);
  системные id генерирует система (раздел 1 каталога).
