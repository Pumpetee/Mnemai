# BP-09.3. Сценарии использования: знакомство и квиз

## 0. Сценарий ввода → BP-09

В описании пути клиента «Знакомство» и квиз не описаны (примечание — BP-09.1). Сценарии
выведены из каталога BP-09 и описания обучения. Покрытие: UC-01–UC-04.

## UC-01. Первое знакомство (интервью)

- **Актор:** Пользователь.
- **Предусловие:** приложение запущено; память доступна (иначе — А3).
- **Основной поток:**
  1. Система предлагает «Знакомство» автоматически при первом знакомстве (решение владельца); повторно
     пользователь запускает его по кнопке — форма интерфейса или API-команда. (FR-01, FR-07)
  2. Система задаёт вопросы при первом знакомстве: о профиле, правилах, проектах и людях; вопросы — друг
     за другом (допущение: порядок вопросов не задан, BP-09.1, «Область вне требований»). (FR-02)
  3. Пользователь отвечает; система записывает каждый ответ как обычный факт памяти по мере его получения
     (допущение: момент записи не задан, BP-09.1, «Область вне требований»); механика записи — BP-07. (FR-03)
- **Альтернативные потоки:**
  - А1 (прерывание): пользователь прерывает интервью → судьба уже данных ответов не описана (BP-09.1,
    «Область вне требований»).
  - А2 (повтор): повторный запуск — по кнопке пользователя (FR-01); что происходит с прежними фактами — не
    описано (BP-09.1, «Область вне требований»).
  - А3 (блокировка): память зашифрована и заблокирована → запросы, которым нужна память, отклоняются;
    интерфейс предлагает ввести пароль — BP-15 (краевые состояния).
- **Постусловие:** ответы записаны как обычные факты памяти; память пополнена (результат BP-09; механика —
  BP-07).
- **Трассировка:** UC-01 → FR-01, FR-02, FR-03, FR-07 → триггер BP-09; BP-09, шаги 1, 2, 4;
  результат BP-09; решение владельца.

## UC-02. Квиз «да»

- **Актор:** Пользователь.
- **Предусловие:** квиз запущен (FR-04, FR-07); в памяти есть факты (иначе — А3).
- **Основной поток:**
  1. Система показывает факт памяти по одному, от простого к сложному. (FR-05)
  2. Пользователь отвечает «да».
  3. Система оставляет факт без изменений. (FR-06)
  4. Система показывает следующий факт по одному, от простого к сложному. (FR-05)
- **Альтернативные потоки:**
  - А1 (другой ответ): «изменилось» — UC-03 (FR-06); «нет» — UC-04 (FR-06).
  - А2 (прерывание): пользователь прерывает квиз → судьба уже показанных фактов не описана (BP-09.1,
    «Область вне требований»).
  - А3 (пустая память): фактов нет → поведение квиза не описано (BP-09.1, «Область вне требований»);
    пустые списки и подсказки вместо ошибок — BP-01 (краевые состояния).
  - А4 (повтор): повторное прохождение квиза не описано (BP-09.1, «Область вне требований»).
- **Постусловие:** факт оставлен без изменений; квиз продолжается со следующим фактом.
- **Трассировка:** UC-02 → FR-04, FR-05, FR-06, FR-07 → триггер BP-09; BP-09, шаги 3, 4.

## UC-03. Квиз «изменилось»

- **Актор:** Пользователь.
- **Предусловие:** квиз запущен (FR-04, FR-07); показан факт (FR-05).
- **Основной поток:**
  1. Пользователь отвечает «изменилось».
  2. Система правит факт по правилам BP-07. (FR-06)
  3. Система показывает следующий факт по одному, от простого к сложному. (FR-05)
- **Альтернативные потоки:**
  - А1 (исправление): как именно пользователь задаёт исправление — не описано (BP-09.1, «Область вне
    требований»).
  - А2 (отмена): правка отменяется через журнал — BP-07.
  - А3 (прерывание / повтор): как в UC-02, А2 и А4.
- **Постусловие:** факт исправлен (механика — BP-07); квиз продолжается.
- **Трассировка:** UC-03 → FR-04, FR-05, FR-06, FR-07 → триггер BP-09; BP-09, шаги 3, 4.

## UC-04. Квиз «нет»

- **Актор:** Пользователь.
- **Предусловие:** квиз запущен (FR-04, FR-07); показан факт (FR-05).
- **Основной поток:**
  1. Пользователь отвечает «нет».
  2. Система удаляет факт по правилам BP-07 (с отменой через журнал). (FR-06)
  3. Система показывает следующий факт по одному, от простого к сложному. (FR-05)
- **Альтернативные потоки:**
  - А1 (отмена): удаление отменяется через журнал — BP-07.
  - А2 (прерывание / повтор): как в UC-02, А2 и А4.
- **Постусловие:** факт удалён (механика — BP-07); квиз продолжается.
- **Трассировка:** UC-04 → FR-04, FR-05, FR-06, FR-07 → триггер BP-09; BP-09, шаги 3, 4.
