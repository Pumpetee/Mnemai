# BP-16.4. Артефакты предметной области: данные пользователя

Процесс BP-16 каталога процессов; основание — требования владельца (глоссарий, разделы 1, 7, 15).
Сущности данных пользователя, их состояния и переходы, правила процесса и словарь терминов. Механика
журнала, памяти, чата, шифрования, синхронизации и настроек не дублируется — ссылки на BP-02, BP-07,
BP-12, BP-13, BP-15 и темы 4.1, 4.2. Пробелы источников — BP-16.1, раздел 7.

## 1. Модель состояний данных пользователя

```
Данные пользователя на его компьютере: память, чаты, журнал, вложения
(собственных серверов нет — BP-16, шаг 1)
        │
        ├─ Экспорт (триггер BP-16)
        │     ├─ память ──► папка открытых Markdown-файлов; при шифровании экспорт запрещён (BP-16, шаг 2)
        │     ├─ журнал ──► экспорт из «Память → История» (BP-16, шаг 2; механика — BP-07)
        │     └─ чаты ──► экспорт из чата (BP-16, шаг 2; BP-02)
        ├─ Удаление (триггер BP-16)
        │     ├─ папка памяти ──► после закрытия приложения/остановки синка; удаляет память и чаты;
        │     │     отмены удаления папки нет (BP-16, шаг 3)
        │     └─ чат/факт ──► через интерфейс; отмена через журнал; вложения остаются в Saves (BP-16, шаг 3; BP-07)
        ├─ Резервные копии (триггер BP-16 — «проверить резервную копию»)
        │     ├─ снапшот до первой правки дня ──► папка сейвов; восстановление — кнопка «восстановить»
        │     │     в журнале (нет правок в день — снапшот не создаётся: допущение) (BP-16, шаг 6)
        │     └─ полная копия ──► на усмотрение пользователя или через синхронизацию (BP-16, шаг 6; BP-13)
        └─ Секреты: защищённое хранилище системы, отдельно от папки памяти;
              удаление — из настроек (BP-16, шаг 4; тема 4.1; BP-12);
              в журналах — только счётчики скрытого (BP-16, шаг 5)
```

## 2. Сущности, состояния и переходы

| Поле | Значение |
|---|---|
| Определение | Всё, что создаёт пользователь: память, чаты, журнал, вложения; лежит на его компьютере, собственных серверов у Mnemai нет (требования, раздел 15; BP-16, шаг 1) |

## 3. Правила процесса

- **Правило локальности.** Всё созданное пользователем — на его компьютере; собственных серверов нет
  (BP-16, шаг 1; BR-01; FR-01; требования, раздел 15).
- **Правило экспорта памяти.** Память экспортируется открытыми Markdown-файлами (папкой); при включённом
  шифровании экспорт памяти запрещён (BP-16, шаг 2; BR-02; FR-02; решение владельца — 20.11.2026).
- **Правило экспорта журнала.** Журнал экспортируется из «Память → История» в Markdown/JSON; числа
  экспорта и ротации подтверждаются (BP-16, шаг 2; BR-03; FR-03; требования, раздел 12).
- **Правило экспорта чатов.** Чаты экспортируются из чата (BP-16, шаг 2; BR-04; FR-04; BP-02).
- **Правило удаления.** Папка памяти удаляется после закрытия приложения или остановки синхронизации,
  вместе с памятью и чатами; отмены удаления папки нет; чат или факт удаляется через интерфейс с отменой
  через журнал; вложения удалённого чата или папки остаются в Saves (BP-16, шаг 3; BR-05, BR-06; FR-05,
  FR-06; BP-07; решение владельца — 20.11.2026).
- **Правило секретов.** Секреты — в защищённом хранилище системы, отдельно от папки памяти; на Linux без
  Secret Service — файл в служебной папке памяти, не шифрован, защищён правами владельца; удаление — из
  настроек; в журналах — только счётчики скрытого (BP-16, шаги 4–5; BR-07, BR-08; FR-07, FR-08; тема 4.1).
- **Правило резервных копий.** Снапшот — до первой правки дня, в папку сейвов; снапшот восстанавливается
  по кнопке «восстановить» в журнале; полная копия папки — на усмотрение пользователя или через
  синхронизацию (BP-16, шаг 6; BR-09, BR-10; FR-09, FR-10; BP-13; решение владельца — 20.11.2026).

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | глоссарий требований (дословно) |
| Данные пользователя | Всё, что создаёт пользователь: память, чаты, журнал, вложения; лежит на его компьютере, собственных серверов у Mnemai нет | требования, раздел 15; BP-16, шаг 1 |

| Удаление чата/факта | Удаление через интерфейс, с отменой через журнал | требования, раздел 15; BP-16, шаг 3; BP-07 |
| Секрет | Ключ API, логин Telegram или VPN-ключ; хранится в защищённом хранилище системы, отдельно от папки памяти; удаляется в настройках | требования, разделы 15 и 7; BP-16, шаг 4 |
