# BP-15.3. Сценарии использования: шифрование памяти

## 0. Сценарий ввода → BP-15

В описании пути клиента шифрование упомянуто только в списке модулей
настроек (примечание — BP-15.1). Сценарии выведены из каталога BP-15 и описания памяти, решений владельца, краевых состояний. Покрытие:
UC-01–UC-06.

## UC-01. Включить пароль шифрования

- **Актор:** Пользователь.
- **Предусловие:** память создана (создание — BP-01); шифрование выключено — память читается и правится
  без приложения (описание памяти).
- **Основной поток:**
  1. Пользователь включает пароль: при создании памяти (визард — BP-01, пароль опционален) или в
     настройках. (FR-01)
  2. Система шифрует текст-файлы памяти; вне приложения они больше не читаются. (FR-02)
  3. Скопированная или синхронизированная копия остаётся зашифрованной в той же мере. (FR-03)
  4. Бинарные файлы (PDF, картинки, записи) и служебные открытые файлы остаются открытыми. (FR-04)
- **Альтернативные потоки:**
  - А1 (отказ): пользователь не включает пароль → память остаётся открытой (читается без приложения, описание памяти).
  - А2 (Windows): пользователь выбирает опцию шифрования средствами файловой системы — отдельный
    механизм (FR-08).
  - А3 (смена/удаление): смена пароля — UC-05 (FR-09); удаление пароля — UC-06 (FR-10).
- **Постусловие:** текст-файлы памяти зашифрованы и читаются только в приложении (результат BP-15).
- **Трассировка:** UC-01 → FR-01, FR-02, FR-03, FR-04, FR-08, FR-09, FR-10 → триггер BP-15;
  BP-15, шаги 1, 2, 5; результат BP-15; решения владельца.

## UC-02. Запуск с заблокированной памятью

- **Актор:** Пользователь.
- **Предусловие:** память зашифрована; приложение запущено; пароль не введён.
- **Основной поток:**
  1. Запросы, которым нужна память, отклоняются ошибкой блокировки. (FR-05; краевые состояния)
  2. Интерфейс предлагает ввести пароль. (FR-05)
  3. Пользователь вводит пароль; система открывает доступ — память читается и правится в приложении.
     (FR-06)
- **Альтернативные потоки:**
  - А1 (неверный пароль): система показывает «пароль не подходит»; попытки не ограничены (FR-06;
    решение владельца).
  - А2 (без пароля): пользователь не вводит пароль → память остаётся заблокированной; запросы
    отклоняются (FR-05).
  - А3 (забытый пароль): пользователь забыл пароль — UC-03 (FR-07).
- **Постусловие:** после ввода пароля память доступна в приложении (результат BP-15); без пароля —
  остаётся заблокированной (FR-05).
- **Трассировка:** UC-02 → FR-05, FR-06, FR-07 → триггер BP-15; BP-15, шаги 3, 4; результат BP-15.

## UC-03. Забытый пароль и recovery-ключ

- **Актор:** Пользователь.
- **Предусловие:** память зашифрована; пароль забыт; recovery-ключ был показан один раз при создании
  пароля (FR-07).
- **Основной поток:**
  1. Пользователь вводит recovery-ключ; система восстанавливает доступ по ключу. (FR-07)
  2. После восстановления память читается и правится в приложении. (FR-06)
- **Альтернативные потоки:**
  - А1 (ключ утерян): recovery-ключ не сохранён → восстановление невозможно (FR-07; решение владельца).
  - А2 (повторный ввод пароля): неверный пароль → сообщение «пароль не подходит», попытки не ограничены
    (FR-06; решение владельца).
- **Постусловие:** доступ восстановлен по recovery-ключу — или без ключа восстановление невозможно
  (решение владельца).
- **Трассировка:** UC-03 → FR-05, FR-06, FR-07 → триггер BP-15; BP-15, шаги 3, 4; решение владельца.

## UC-04. Копия зашифрованной памяти

- **Актор:** Пользователь.
- **Предусловие:** память зашифрована (FR-02).
- **Основной поток:**
  1. Пользователь копирует папку памяти или включает синхронизацию (синхронизация — BP-13).
  2. Копия — скопированная или синхронизированная — остаётся зашифрованной в той же мере. (FR-03)
  3. Бинарные и служебные открытые файлы в копии остаются открытыми. (FR-04)
- **Альтернативные потоки:**
  - А1 (синк): синхронизированная копия зашифрована в той же мере, что и на этом компьютере — BP-13,
    шаг 4 (ссылка).
  - А2 (открытие копии): зашифрованная копия при открытии требует пароль — поведение как в UC-02
    (допущение: явно не описано, BP-15.1, «Область вне требований»).
- **Постусловие:** копия памяти зашифрована в той же мере, что и исходная папка (FR-03).
- **Трассировка:** UC-04 → FR-02, FR-03, FR-04, FR-05, FR-06 → триггер BP-15; BP-15, шаги 1–3;
  BP-13, шаг 4 (ссылка).

## UC-05. Смена пароля

- **Актор:** Пользователь.
- **Предусловие:** память зашифрована (FR-02).
- **Основной поток:**
  1. Пользователь меняет пароль в настройках. (FR-09)
  2. Система перешифровывает текст-файлы новым паролем. (FR-09)
- **Альтернативные потоки:**
  - А1 (отказ): пользователь отменяет смену → пароль остаётся прежним (FR-09).
- **Постусловие:** текст-файлы зашифрованы новым паролем (решение владельца).
- **Трассировка:** UC-05 → FR-09 → решение владельца.

## UC-06. Удаление пароля

- **Актор:** Пользователь.
- **Предусловие:** память зашифрована (FR-02).
- **Основной поток:**
  1. Пользователь удаляет пароль. (FR-10)
  2. Система полностью расшифровывает текст-файлы. (FR-10)
- **Альтернативные потоки:**
  - А1 (отказ): пользователь отменяет удаление → пароль остаётся, память зашифрована (FR-10).
- **Постусловие:** текст-файлы полностью расшифрованы; память снова читается без приложения (описание памяти;
  решение владельца).
- **Трассировка:** UC-06 → FR-10 → решение владельца; описание памяти.
