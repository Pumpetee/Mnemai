# BP-10.4. Артефакты предметной области: встречи, голос, OCR

Процесс BP-10 каталога процессов; основание — требования владельца (глоссарий, разделы 6, 8). Сущности
скрайба встреч и голосовой команды, их состояния и переходы, правила процесса и словарь терминов.
Механика чата, памяти, провайдеров и настроек не дублируется — ссылки на BP-02, BP-07, BP-11, BP-12 и темы
4.1, 4.3, 4.5, 4.7. Пробелы источников — BP-10.1, раздел 7.

## 1. Модель состояний встречи и голосовой команды

```
Начало записи встречи (триггер BP-10)
        │
        ├─ пресет Private / Quality / Fast ──► весь путь сразу:
        │     Private — только локальные модели; Quality — облако при ключе, иначе локально (по умолчанию);
        │     Fast — короткие записи локально, длинные — в облако (BP-10, шаг 3)
        ▼
Запись: две дорожки — микрофон + звук компьютера (видно, кто говорит) (BP-10, шаг 1)
        │
        └─ остановка записи (не более 5 часов; способ остановки — допущение: не описан, BP-10.1, раздел 7)
        ▼
Распознавание: локально (бесплатно) или облачным сервисом (≈ $0.36/час, цена на дату)
        │     (вариант задаёт пресет — BP-10, шаг 3)
        ▼
Чистка: вырезаются тишина, фразы-ошибки, эхо (BP-10, шаг 2)
        │
        ▼
Итог любым подключённым ИИ (включая локальный): решения, задачи, владельцы (BP-10, шаг 4)
        │
        ▼
Итог в чате на языке общения из профиля (результат BP-10; тема 4.5)

Голосовая команда (триггер BP-10)
        ▼
Распознавание речи на компьютере ──► сообщение отправлено в чат (BP-10, шаг 5; дальше — BP-02)
```

| Переход | Откуда → куда | Правило |
|---|---|---|
| Начало записи | — → Запись идёт | Триггер BP-10; FR-01 |
| Выбор пресета | — → Путь задан пресетом | BP-10, шаг 3; FR-04; Quality — пресет по умолчанию |
| Запись | Запись идёт → Запись остановлена | BP-10, шаг 1; FR-01; остановка — допущение (BP-10.1, раздел 7) |
| Распознавание | Запись остановлена → Расшифровка получена | BP-10, шаг 2; FR-02 (вариант задаёт пресет — FR-04) |
| Чистка | Расшифровка → Очищена (тишина, ошибки, эхо вырезаны) | BP-10, шаг 2; FR-03 |
| Итог | Очищена → Итог в чате | BP-10, шаг 4; FR-05; генерация текста — BP-02 |
| Язык итога | Итог → на языке общения профиля | Тема 4.5; FR-08 |
| Голосовая команда | — → Распознана → Сообщение в чате | Триггер BP-10; BP-10, шаг 5; FR-06; дальше — BP-02 |
| Платформа | — → Доступно/Недоступно (есть локальные движки) | Тема 4.7; FR-07; матрица уточняется (BP-10.1, раздел 7) |
| Офлайн | Расшифровка локально / голосовая команда — на компьютере (допущение) | Краевые состояния требований; BP-02, шаг 8; BP-10.1, раздел 7 |

## 2. Сущности, состояния и переходы

### 2.1 Запись встречи

| Поле | Значение |
|---|---|
| Определение | Запись встречи с микрофона и звука компьютера (требования, раздел 6; BP-10, шаг 1) |
| Атрибуты | Две дорожки: микрофон и звук компьютера — видно, кто говорит (FR-01); длительность — не более 5 часов; место хранения — не описано (BP-10.1, раздел 7) |
| Состояния | Идёт → Остановлена (способ остановки — допущение, BP-10.1, раздел 7) → Распознана |
| Переходы | Начать (FR-01); остановить (допущение); передать на распознавание (FR-02) |

### 2.2 Расшифровка

| Поле | Значение |
|---|---|
| Определение | Текст, полученный из записи распознаванием — локально (бесплатно) или облачным сервисом (требования, раздел 6; BP-10, шаг 2) |
| Атрибуты | Вариант распознавания: локальный / облачный — задаёт пресет (FR-02, FR-04); цена облачного — внешнего сервиса на дату, ориентир ≈ $0.36/час (FR-02) |
| Состояния | Получена → Очищена (вырезаны тишина, фразы-ошибки, эхо — FR-03) |
| Переходы | Распознать (FR-02); очистить (FR-03) |

### 2.3 Итог встречи

| Поле | Значение |
|---|---|
| Определение | Итог встречи: решения, задачи и их владельцы; готовит любой подключённый ИИ, включая локальный (требования, раздел 6; BP-10, шаг 4) |
| Атрибуты | Решения; задачи; владельцы задач (требования, раздел 6); язык — общения из профиля (FR-08); исполнитель — выбранный ИИ (выбор — допущение, BP-10.1, раздел 7) |
| Состояния | Готовится → Показан в чате (результат BP-10) |
| Переходы | Подготовить любым ИИ (FR-05); показать в чате (FR-05); запись решений и задач в память — BP-07 (ссылка) |

### 2.4 Пресет

| Поле | Значение |
|---|---|
| Определение | Пресет Private / Quality / Fast: задаёт весь путь записи и распознавания сразу (требования, раздел 6; BP-10, шаг 3) |
| Атрибуты | Название из фиксированного набора: Private, Quality, Fast; определения: Private — только локальные модели; Quality — облачное распознавание при наличии ключа, иначе локальное (пресет по умолчанию); Fast — короткие записи локально, длинные — в облако (FR-04) |
| Состояния | Выбран → Применяется к пути записи и распознавания |
| Переходы | Выбрать (FR-04); применить к следующей встрече — допущение (BP-10.1, раздел 7); без выбора действует Quality (по умолчанию) |
| Примечание | Список моделей определяется установленными локальными моделями и провайдерами |

### 2.5 Голосовая команда

| Поле | Значение |
|---|---|
| Определение | Речь пользователя, распознаваемая на компьютере и отправляемая в чат сообщением (требования, раздел 6; BP-10, шаг 5) |
| Атрибуты | Распознанный текст сообщения (FR-06) |
| Состояния | Произнесена → Распознана → Отправлена в чат (результат BP-10) |
| Переходы | Распознать на компьютере (FR-06); отправить сообщением в чат (FR-06); дальнейшая обработка — BP-02 |

### 2.6 Распознавание (вариант)

| Поле | Значение |
|---|---|
| Определение | Вариант распознавания записи: локальный (бесплатно) или облачный сервис (цена на дату, ориентир ≈ $0.36/час) (требования, раздел 6; BP-10, шаг 2) |
| Атрибуты | Локальный — без оплаты внешнего сервиса; облачный — внешний сервис с ценой на дату (FR-02) |
| Состояния | Выбран (пресетом) → Применён (расшифровка получена) |

| Примечание | Лимит вызова 300 с (тема 4.3) к облачному распознаванию не применяется; применимость правил темы 4.1 к отправке записи не описана (BP-10.1, раздел 7) |

### 2.7 Платформа (матрица голоса и распознавания)

| Поле | Значение |
|---|---|
| Определение | Платформы, где голос и распознавание речи работают: только там, где есть локальные движки; матрица уточняется (требования, раздел 8; тема 4.7; BP-10.1, раздел 7) |
| Атрибуты | Наличие локальных движков голоса и распознавания речи на платформе |

| Примечание | OCR сканов и картинок — BP-11 (ссылка); к BP-10 относится только голос и распознавание речи |

## 3. Правила процесса

- **Правило двух дорожек.** Запись ведётся двумя дорожками — микрофон и звук компьютера, чтобы было
  видно, кто говорит (BP-10, шаг 1; BR-01; FR-01).
- **Правило длительности.** Запись встречи длится не более 5 часов (FR-01; решение владельца —
  20.11.2026).
- **Правило распознавания.** Запись распознаётся локально (бесплатно) или облачным сервисом (цена внешнего
  сервиса на дату, ориентир ≈ $0.36/час); вариант задаёт пресет; лимит вызова 300 с к облачному
  распознаванию не применяется (BP-10, шаг 2; BR-02; FR-02; FR-04; решение владельца — 20.11.2026).
- **Правило чистки.** Перед итогом вырезаются тишина, фразы-ошибки и эхо (BP-10, шаг 2; BR-03; FR-03).
- **Правило пресетов.** Пресеты Private / Quality / Fast задают весь путь записи и распознавания сразу:
  Private — только локальные модели; Quality — облачное распознавание при наличии ключа, иначе локальное
  (пресет по умолчанию); Fast — короткие записи локально, длинные — в облако; список моделей определяется
  установленными локальными моделями и провайдерами (BP-10, шаг 3; BR-04; FR-04; решение владельца —
  20.11.2026).
- **Правило итога.** Итог — решения, задачи и их владельцы — готовит любой подключённый ИИ, включая
  локальный; итог появляется в чате (BP-10, шаг 4 и результат; BR-05; FR-05; генерация текста — BP-02).
- **Правило голосовой команды.** Речь распознаётся на компьютере и отправляется в чат сообщением
  (BP-10, шаг 5; BR-06; FR-06; дальше — BP-02).
- **Правило языка.** Итог ведётся на языке общения из профиля (тема 4.5; BR-07; FR-08; требования,
  раздел 8).
- **Правило платформ.** Голос и распознавание речи — только там, где есть локальные движки; матрица
  уточняется (тема 4.7; BR-08; FR-07; требования, раздел 8).

|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | глоссарий требований (дословно) |
| Провайдер | Источник ИИ: подписка Claude (Claude Code), подписка ChatGPT (Codex), ключ API, локальная модель, Harness-агент; итог встречи готовит любой подключённый ИИ, включая локальный | глоссарий требований (дословно); требования, раздел 6 |
| Скрайб встреч | Запись встречи, распознавание и итог: решения, задачи и их владельцы | требования, раздел 6; BP-10, «Назначение» |
| Дорожка | Отдельная линия записи: микрофон и звук компьютера пишутся двумя дорожками — видно, кто говорит | требования, раздел 6; BP-10, шаг 1 |

| Чистка записи | Вырезание тишины, фраз-ошибок и эха перед итогом | требования, раздел 6; BP-10, шаг 2 |
