# BP-15.2. Функциональные требования: шифрование памяти

## 1. Включение пароля и шифрование (триггер BP-15; BP-15, шаг 1)

### FR-01 — Включение пароля
Система должна давать включить пароль шифрования памяти — при создании памяти или в настройках.
**Приёмка:** пароль включается при создании памяти (визард, пароль опционален — BP-01) или в настройках;
после включения текст-файлы памяти зашифрованы (FR-02).
(Триггер BP-15; описание памяти, онбординг и приложение; BP-01)

### FR-02 — Шифрование текст-файлов
Система должна при включённом пароле шифровать текст-файлы памяти (AES-256-GCM): .md, .json, .jsonl,
.txt, .csv, .tsv, .log, .yml, .yaml, .html, .htm — и читать/править их только внутри приложения.
**Приёмка:** перечисленные типы файлов зашифрованы; вне приложения они не читаются; в приложении — читаются
и правятся.
(BP-15, шаг 1; описание памяти)

### FR-03 — Копии остаются зашифрованными
Система должна обеспечивать, что скопированная или синхронизированная копия памяти остаётся зашифрованной
в той же мере.
**Приёмка:** копия папки памяти — скопированная вручную или синхронизированная — остаётся зашифрованной;
синхронизированная копия — BP-13, шаг 4.
(BP-15, шаг 1; описание памяти, онбординг и приложение; BP-13)

### FR-04 — Бинарные и открытые файлы не шифруются
Система должна оставлять бинарные файлы (PDF, картинки, записи) и служебные открытые (PLAIN) файлы
открытыми и предупреждать в интерфейсе, что бинарные файлы не шифруются.
**Приёмка:** бинарные и служебные открытые файлы не шифруются и остаются читаемыми без приложения;
шифруются только текст-файлы — зафиксировано; интерфейс предупреждает, что бинарные файлы не шифруются
(решение владельца).
(BP-15, шаг 2; описание памяти; тема 4.8; решение владельца)

## 2. Заблокированная память (триггер BP-15; BP-15, шаг 3)

### FR-05 — Ошибка блокировки
Система должна при запуске с зашифрованной памятью без введённого пароля отвечать ошибкой блокировки на
запросы, которым нужна память, и предлагать ввести пароль.
**Приёмка:** запросы, которым нужна память, отклоняются ошибкой блокировки; интерфейс предлагает ввести
пароль; после ввода пароля память доступна (FR-06).
(BP-15, шаг 3; краевые состояния)

### FR-06 — Ввод пароля и разблокировка
Система должна принимать ввод пароля и открывать доступ к памяти после его ввода; при неверном пароле —
сообщение «пароль не подходит» без ограничения числа попыток.
**Приёмка:** после ввода пароля текст-файлы памяти читаются и правятся в приложении (результат BP-15); при
неверном пароле показано «пароль не подходит», попытки не ограничены (решение владельца).
(Результат BP-15; BP-15, шаг 3; описание памяти, краевые состояния; решение владельца)

## 3. Забытый пароль и механизм Windows (BP-15, шаги 4–5)

### FR-07 — Восстановление по recovery-ключу
Система должна показывать recovery-ключ один раз при создании пароля и восстанавливать забытый пароль
только по этому ключу.
**Приёмка:** при создании пароля recovery-ключ показан один раз; восстановление забытого пароля — только по
recovery-ключу; без ключа восстановление невозможно (решение владельца).
(BP-15, шаг 4; описание памяти; решения владельца; тема 4.8; решение владельца)

### FR-08 — Отдельный механизм Windows
Система должна на Windows предлагать отдельный механизм шифрования средствами файловой системы.
**Приёмка:** на Windows доступна опция шифрования средствами файловой системы; она действует отдельно от
пароля; применима ли опция вместе с паролем — не описано (BP-15.1, «Область вне требований»).
(BP-15, шаг 5; описание памяти)

## 4. Смена и удаление пароля (решения владельца)

### FR-09 — Смена пароля с перешифрованием
Система должна позволять сменить пароль в настройках; при смене текст-файлы перешифровываются.
**Приёмка:** смена пароля выполняется в настройках; после смены текст-файлы зашифрованы новым паролем
(решение владельца).
(Решение владельца)

### FR-10 — Удаление пароля с полной расшифровкой
Система должна позволять удалить пароль; при удалении текст-файлы полностью расшифровываются.
**Приёмка:** после удаления пароля текст-файлы полностью расшифрованы — память снова читается без
приложения (описание памяти; решение владельца).
(Решение владельца; описание памяти)
