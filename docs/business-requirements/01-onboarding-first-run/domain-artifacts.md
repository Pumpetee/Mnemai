# BP-01.4. Артефакты предметной области: онбординг и первый запуск

## 1. Модель состояний онбординга

```
Первый запуск без памяти (триггер BP-01)
        │
        ▼
Визард: [1] Тема → [2] Язык → [3] Обращение → [4] Память
        │                                      ├─ Создать (путь по умолчанию — домашняя папка; структура — BP-07)
        │                                      │      └─ Пароль? → задать / пропустить (BP-15)
        │                                      └─ Открыть существующую (зашифрована? → ввод пароля, BP-15)
        ▼
После визарда: подключение хотя бы одного ИИ
        ├─ подключён ≥ 1 ──→ «Готов к первому вопросу» (BR-08)
        └─ не подключён ──→ «Нет ИИ»: чат объясняет причину и ведёт в настройки;
                             память, журнал, команды без модели работают (BP-02, тема 4.4)
```

| Переход | Откуда → куда | Правило |
|---|---|---|
| Запуск без памяти | — → Визард | Триггер BP-01; раздел 14 |
| Следующий шаг визарда | Шаг → следующий шаг | Порядок фиксирован (BR-02; раздел 8) |
| Создать память | Шаг «память» → Память создана | BP-01, шаг 2; структура — BP-07; тема, язык, обращение и имя — в профиль (BR-13) |
| Открыть память | Шаг «память» → Память открыта | BP-01, шаг 2 |
| Задать/пропустить пароль | Шаг «память» → шифрование по BP-15 | BP-01, шаг 3 |
| Подключить первый ИИ | После визарда → «Готов» | BP-01, шаг 4; детали — BP-12 |
| Отложить подключение | После визарда → «Нет ИИ» | BP-02, шаг 7; раздел 14 |
| Повторный запуск | — → Рабочее окно (визард не открывается) | Тема 4.7; FR-11 |
| Закрытие визарда | Визард прерван → при следующем запуске визард заново | Решение владельца 20.11.2026 |
| Возврат к шагу | Рабочее окно → любой шаг визарда | BP-01, шаг 5; через настройки — BP-12 |
| Блокировка памяти | Память открыта → Заблокирована | BP-15; раздел 14 |

## 2. Сущности, состояния и переходы

### 2.1 Память (папка памяти)

| Поле | Значение |
|---|---|
| Определение | Папка Markdown на компьютере пользователя (разделы 0, 1) |
| Атрибуты | Путь (по умолчанию — домашняя папка пользователя, папка Mnemai — разделы 1, 8); структура/раскладка — BP-07; признак шифрования — BP-15 |
| Состояния | Не создана → Создаётся → Создана и открыта; Заблокирована (зашифрована, пароль не введён — BP-15) |
| Переходы | Создать (визард, шаг «память» → структура по BP-07); Открыть существующую (визард); Заблокировать/Разблокировать (ввод пароля — BP-15); Удалить (BP-16 — ссылка) |

### 2.2 Профиль пользователя

| Поле | Значение |
|---|---|
| Определение | Профиль пользователя в памяти; язык общения задаётся в профиле (раздел 8) |
| Атрибуты | Обращение («как к тебе обращаться» — раздел 8); имя; язык общения (раздел 8, тема 4.5); портрет 2–3 предложений (пополняется обучением — см. BP-07, BP-08) |
| Состояния | Не заполнен → Заполнен (обращение, имя и язык заданы) |
| Переходы | Заполнение при создании памяти: система сохраняет тему, язык, обращение и имя в профиль (BP-01, шаг 2; BR-13); изменение через настройки (BP-12); пополнение портрета — BP-08 (ссылка) |
| Примечание | Имя и обращение (в том числе «ты/вы» — правила обращения ИИ) сохраняются в профиль/портрет при создании памяти; изменяются в настройках (см. BP-12). Раздел 8, сохранение выбора онбординга |

### 2.3 Настройки языка и темы

| Поле | Значение |
|---|---|
| Язык интерфейса | Значения: девять языков (раздел 8); состояния: Не выбран → Выбран; переходы: выбор на шаге визарда, смена в настройках (BP-12); эффект: интерфейс на выбранном языке, ответы ИИ следуют выбранному языку (тема 4.5) |
| Тема | Значения: Светлая / Тёмная (раздел 8); состояния: Не выбрана → Выбрана; переходы: выбор на первом шаге визарда, смена в настройках (BP-12) |

### 2.4 Пароль шифрования памяти

| Поле | Значение |
|---|---|
| Определение | Необязательный пароль, защищающий текст-файлы памяти (разделы 1, 8) |
| Состояния | Не задан (шифрование выключено — раздел 1); Задан (память зашифрована — BP-15); Введён / Не введён при запуске (блокировка — BP-15) |
| Переходы | Задать при создании памяти (BP-01 предлагает — BP-01, шаг 3; включение — BP-15); Задать в настройках (BP-15); Ввести при запуске (BP-15); Забыт — восстановление по ключу восстановления (BP-15; решение владельца 20.11.2026) |

### 2.5 Подключённый ИИ

| Поле | Значение |
|---|---|
| Определение | Провайдер ИИ, выбранный и работоспособный; готовность к первому вопросу требует хотя бы одного (BR-05, BR-08) |
| Атрибуты | Тип провайдера: подписка Claude (Claude Code), подписка ChatGPT (Codex), ключ API, локальная модель, Harness-агент (тема 4.3); работоспособность |
| Состояния | Не подключён ни один → Подключается → Подключён и работает; Нерабочий (сбой — тема 4.3) |
| Переходы | Подключить первый ИИ (BP-01, шаг 4); Добавить/изменить — BP-12; Сбой → Нерабочий (помечается, не попадает в списки моделей — тема 4.3) |

## 3. Правила создания и открытия папки памяти

- Создание и открытие выполняются на шаге «память» визарда; позже — через возврат к шагу из настроек (BP-01, шаги 2, 5; BP-12).
- Путь по умолчанию при создании — домашняя папка пользователя (папка Mnemai) (разделы 1, 8).
- Структура создаваемой папки — по правилам BP-07; BP-01 её не описывает (BP-01, шаг 2).
- Пароль шифрования — необязателен; включение и поведение зашифрованной памяти — по правилам BP-15 (BP-01, шаг 3).
- При открытии существующей зашифрованной папки без введённого пароля — ошибка блокировки, интерфейс предлагает ввести пароль (BP-15; раздел 14).
- При создании памяти система должна сохранить выбранные тему, язык, обращение и имя в профиль; их можно изменить в настройках (см. BP-12). (Раздел 8, сохранение выбора онбординга.)
- Человекочитаемые коды в процессе не используются: в источниках не описаны (раздел 6 каталога); системные id генерирует система (раздел 1 каталога).

## 4. Словарь терминов процесса

Термины согласованы с разделом 0.2 (термины) human-requirements.txt; определения раздела 0.2 приводятся дословно, новые термины процесса выводятся из раздела 8.

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | Раздел 0.2 (дословно) |
| Память | Папка Markdown на компьютере пользователя (по умолчанию — папка Mnemai в домашней папке) | Раздел 1 |
| Провайдер | Источник ИИ: подписка Claude (Claude Code), подписка ChatGPT (Codex), ключ API, локальная модель, Harness-агент | Раздел 0.2 (дословно) |
| Клиент | Правило доступа: какие части памяти и с какими правами видит конкретный ИИ; в BP-01 не настраивается (см. BP-12, тема 4.1) | Раздел 0.2 |
| Скоуп | Раздел памяти: профиль, правила, проекты, карточки, люди, решения, входящие, заметки | Раздел 0.2 (дословно) |
| Визард онбординга | Последовательность из четырёх шагов при первом запуске: тема (светлая/тёмная) → язык → «как к тебе обращаться» → память (создать/открыть, опционально пароль) | Раздел 8; BP-01, шаг 1 |
| Обращение | Ответ пользователя на вопрос «как к тебе обращаться», шаг визарда; сохраняется в профиль при создании памяти, изменяется в настройках (см. BP-12) | Раздел 8, сохранение выбора онбординга |
| Пароль шифрования | Необязательный пароль, защищающий текст-файлы памяти; поведение — BP-15 | Разделы 1, 8 |
| Подключённый ИИ | Провайдер, выбранный и работоспособный; готовность к первому вопросу требует хотя бы одного | Раздел 8; BP-01, шаг 4; BR-05 |
| Первый вопрос | Первый запрос пользователя в чате после подключения первого ИИ — результат BP-01 | Раздел 8; BP-01, результат |
| Готов к первому вопросу | Состояние после онбординга: память создана/открыта, язык/тема/обращение выбраны, подключён хотя бы один ИИ | BP-01, результат; BR-08 |

## 5. Идентификаторы и коды

- Системные id генерирует система (правило каталога, раздел 1).
- Человекочитаемые коды, вводимые пользователем, в BP-01 отсутствуют: в источниках они не описаны (раздел 6 каталога). Если такие коды появятся — проверка уникальности по общему правилу каталога (раздел 1).
