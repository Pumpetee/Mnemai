## UC-01. Подключить внешний клиент (Claude Code / Claude Desktop / Cursor)

- **Актор:** Пользователь (задаёт права и подтверждает), Внешний MCP-клиент (подключается и запрашивает),
  Система.
- **Предусловие:** права клиента заданы в настройках (BP-12, шаг 4; тема 4.1); клиент — из поддерживаемых
  (FR-01).
- **Основной поток:**
  1. Внешний клиент подключается к инструментам Mnemai через отдельное MCP-подключение. (FR-01)
  2. Система показывает клиенту каталог инструментов (56, по группам). (FR-02; допущение: каталог виден с
     учётом прав клиента — BP-05.1, раздел 7; BP-05.4, 2.5)
  3. ИИ клиента запрашивает инструмент. (FR-01)
  4. Система сверяет запрос с правами клиента: скоупы чтения/записи, скрытые теги. (FR-03, FR-04)
  5. Система спрашивает «да» — всегда, независимо от тумблера разрешений чата. (FR-06)
  6. После «да» система исполняет вызов в пределах прав клиента и возвращает результат клиенту. (FR-05)
- **Альтернативные потоки:**
  - А1 («нет»): вызов не выполняется; отказ возвращён клиенту (FR-05, FR-06).
  - А2 (вне прав): чтение или запись вне скоупов клиента — вызов отклоняется (FR-03; UC-02).
  - А3 (скрытые теги): данные со скрытыми тегами клиенту не отдаются (FR-04; UC-03).
  - А4 (запрещённый путь): вызов затрагивает запрещённые пути — UC-06 (FR-08).
  - А5 (прогон): запрошен проверочный прогон — отдельное «да», UC-05 (FR-07).
  - А6 (повторный вызов): каждый следующий вызов — отдельное «да» (FR-06; UC-04).
  - А7 (настройка прав): права клиента меняются в настройках — BP-12 (FR-03, FR-04).
  - А8 (неподдерживаемый клиент): клиент за пределами названных — перечень «и другие» не приведён
    (BP-05.1, раздел 7).
- **Постусловие:** клиент подключён; инструменты доступны в пределах прав; каждый вызов подтверждён;
  результат (выполнение или отказ) возвращён клиенту.
- **Трассировка:** UC-01 → FR-01, FR-02, FR-03, FR-04, FR-05, FR-06, FR-07, FR-08 → BP-05, шаги 1–4;
  результат.

## UC-02. Инструмент в рамках прав клиента (скоупы чтения/записи)

- **Актор:** Внешний MCP-клиент (ИИ через клиент — запрашивает), Система, Пользователь (подтверждает).
- **Предусловие:** клиент подключён (UC-01); скоупы чтения и записи клиента заданы (BP-12, шаг 4).
- **Основной поток:**
  1. ИИ клиента запрашивает чтение части памяти (или запись в неё). (FR-01, FR-02)
  2. Система сверяет часть памяти со скоупами чтения и записи клиента. (FR-03)
  3. Часть разрешена — система спрашивает «да». (FR-06)
  4. После «да» инструмент выполняется; результат возвращён клиенту. (FR-05)
- **Альтернативные потоки:**
  - А1 (вне прав чтения): часть не входит в скоупы чтения клиента — вызов отклоняется (FR-03).
  - А2 (вне прав записи): запись в часть без права записи отклоняется (FR-03).
  - А3 (скрытые теги): из разрешённой части исключаются скрытые теги — UC-03 (FR-04).
  - А4 (запрещённый путь): вызов затрагивает запрещённые пути — UC-06 (FR-08).
  - А5 (отмена записи): запись отменяется через «Историю» — BP-07 (FR-05; тема 4.2).
  - А6 (заблокированная память): вызовы, которым нужна память, отклоняются с запросом пароля — UC-08
    (FR-13; BP-15).
- **Постусловие:** инструмент выполнен в пределах скоупов клиента — или отклонён; результат у клиента;
  запись в журнале и отменяема.
- **Трассировка:** UC-02 → FR-01, FR-02, FR-03, FR-04, FR-05, FR-06, FR-08 → BP-05, шаги 1–4; результат.

## UC-03. Скрытые теги

- **Актор:** Внешний MCP-клиент (запрашивает), Система (фильтрует), Пользователь (настраивает — BP-12).
- **Предусловие:** у части памяти теги скрыты от этого клиента (BP-12, шаг 4; тема 4.1); клиент подключён
  (UC-01).
- **Основной поток:**
  1. Клиент запрашивает раздел памяти, содержащий скрытые от него теги. (FR-02)
  2. Система исключает части со скрытыми тегами из результата. (FR-04)
  3. Факт-архив не отдаётся никогда. (FR-04; BP-07)
  4. Результат без скрытых частей возвращён клиенту. (FR-05)
- **Альтернативные потоки:**
  - А1 (настройка): скрытые теги и замок на тему задаются в BP-12 (тема 4.1); система применяет настройку
    (FR-04).
  - А2 (правило едино): то же правило прав действует для чата и MCP — расхождений между каналами нет
    (FR-03, FR-04; тема 4.1).
  - А3 (попытка записи): запись в скрытую часть — вне прав клиента (FR-03; UC-02, А2).
- **Постусловие:** скрытые части памяти клиенту не выданы; факт-архив не передан.
- **Трассировка:** UC-03 → FR-02, FR-03, FR-04, FR-05 → BP-05, шаги 2, 4; результат.

## UC-04. Обязательное «да» на каждый вызов

- **Актор:** Пользователь (подтверждает), Внешний MCP-клиент (запрашивает), Система.
- **Предусловие:** клиент подключён (UC-01); ИИ клиента запрашивает вызов инструмента или проверочный
  прогон.
- **Основной поток:**
  1. ИИ клиента запрашивает вызов инструмента.
  2. Система спрашивает отдельное «да» — всегда, при любом положении тумблера разрешений чата. (FR-06)
  3. Пользователь жмёт «да»; система исполняет вызов и возвращает результат клиенту. (FR-05)
  4. Каждый следующий вызов — отдельное «да». (FR-06)
- **Альтернативные потоки:**
  - А1 («нет»): вызов не выполняется; отказ возвращён клиенту (FR-05).
  - А2 (таймаут): «да» не получено за 600 с — ожидание прекращается по правилам BP-04 (FR-06; тема 4.8).
  - А3 (прогон): проверочный прогон — отдельное «да», UC-05 (FR-07).
  - А4 (разговор чата): «Да для этого разговора» к вызовам внешних клиентов не применяется; список
    разрешённых действий разговора ими не пополняется (FR-06; чат).
- **Постусловие:** вызов выполнен только с явным «да»; список разрешённых действий разговора не изменён.
- **Трассировка:** UC-04 → FR-05, FR-06, FR-07 → BP-05, шаг 3; результат.

## UC-05. Проверочный прогон инструментов (mcp_smoke_all) через внешнего клиента

- **Актор:** Пользователь (подтверждает), Внешний MCP-клиент (запрашивает), Система (исполняет прогон).
- **Предусловие:** ИИ клиента запросил полный проверочный прогон всех инструментов; «да» получено (FR-06);
  доступность прогона внешнему клиенту — допущение (BP-05.1, раздел 7).
- **Основной поток:**
  1. Система выполняет полный прогон всех инструментов в безопасной приватной временной папке. (FR-07)
  2. Тестовые записи помечаются и удаляются; буфер обмена восстанавливается; инструменты рабочего стола
     пропускаются. (FR-07)
  3. Результат прогона возвращён клиенту. (FR-05)
- **Альтернативные потоки:**
  - А1 («нет»): прогон не выполняется (FR-06).
  - А2 (повтор): каждый следующий прогон — отдельное «да» (FR-06).
  - А3 (запрещённый путь): прогон не открывает запрещённые пути — deny-list действует всегда (FR-08;
    UC-06).
- **Постусловие:** прогон завершён; тестовые записи удалены; буфер обмена восстановлен; инструменты
  рабочего стола не запускались.
- **Трассировка:** UC-05 → FR-05, FR-06, FR-07, FR-08 → BP-05, шаги 1, 3; результат.

## UC-06. Запрещённый путь (deny-list)

- **Актор:** Внешний MCP-клиент (ИИ запрашивает), Система (отклоняет), Пользователь (не может разрешить).
- **Предусловие:** ИИ клиента запрашивает файловый инструмент или команду, затрагивающие запрещённые пути
  секретов.
- **Основной поток:**
  1. Клиент запрашивает действие с запрещённым путём.
  2. Система отклоняет: файловые инструменты не читают и не пишут эти пути, команды с этими путями
     отклоняются — ни при каком разрешении. (FR-08)
  3. Отказ возвращён клиенту. (FR-05)
- **Альтернативные потоки:**
  - А1 («да»): даже «да» пользователя не открывает доступ — запрет действует при любых правах клиента
    (FR-08).
  - А2 (расширение): расширение доступа — только с явного разрешения пользователя и после ревью; deny-list
    остаётся чёрным списком защиты секретов, а не песочницей (ограничения; тема 4.1).
  - А3 (права клиента): запрет действует при любых скоупах чтения/записи клиента (FR-08, FR-03).
- **Постусловие:** действие не выполнено; секреты не затронуты.
- **Трассировка:** UC-06 → FR-03, FR-05, FR-08 → BP-05, шаги 1 («см. BP-04»), 2; результат; тема 4.1; инструменты, ограничения.

## UC-07. Сторонний MCP-сервер не поддерживается

- **Актор:** Пользователь (пытается подключить), Внешний MCP-клиент, Система.
- **Предусловие:** пользователь хочет подключить сторонний MCP-сервер как источник инструментов.
- **Основной поток:**
  1. Подключение стороннего MCP-сервера как источника инструментов не поддерживается. (FR-11)
  2. Инструменты внешним клиентам даёт только собственный MCP-сервер Mnemai. (FR-01, FR-02)
- **Альтернативные потоки:**
  - А1 (каталог): каталог из 56 инструментов — только собственный (FR-02).
  - А2 (вопрос снят): открытый вопрос «сторонние MCP-серверы» (открытые вопросы, п.4) закрыт этим решением (FR-11).
- **Постусловие:** сторонний источник инструментов не подключён; доступны только собственные инструменты.
- **Трассировка:** UC-07 → FR-01, FR-02, FR-11 → BP-05, шаг 1; решение владельца (20.11.2026).

## UC-08. Заблокированная память

- **Актор:** Внешний MCP-клиент (запрашивает), Система, Пользователь (вводит пароль).
- **Предусловие:** память зашифрована и заблокирована (BP-15; крайние состояния).
- **Основной поток:**
  1. ИИ клиента запрашивает вызов, которому нужна память.
  2. Система отказывает в вызове с запросом пароля. (FR-13)
  3. Пользователь вводит пароль (BP-15); после разблокировки вызов выполняется по общим правилам (FR-13,
     FR-06).
- **Альтернативные потоки:**
  - А1 (память не нужна): вызовы, которым память не нужна, не затрагиваются — BP-15 (FR-13).
  - А2 (пароль не введён): вызов остаётся отклонённым (FR-13).
- **Постусловие:** вызов отклонён с запросом пароля — или выполнен после разблокировки памяти.
- **Трассировка:** UC-08 → FR-06, FR-13 → решение владельца (20.11.2026); BP-15; крайние состояния.

## UC-09. Офлайн: только локальные модели

- **Актор:** Внешний MCP-клиент (запрашивает), Система, Пользователь.
- **Предусловие:** нет сети (офлайн).
- **Основной поток:**
  1. ИИ клиента запрашивает вызов инструмента.
  2. Система обслуживает вызовы только локальными моделями. (FR-14)
  3. Результат возвращён клиенту. (FR-05)
- **Альтернативные потоки:**
  - А1 (облачная модель): облачные модели в офлайне недоступны — вызовы обслуживаются локальными моделями
    (FR-14; крайние состояния).
- **Постусловие:** вызовы обслужены локальными моделями; результат у клиента.
- **Трассировка:** UC-09 → FR-05, FR-14 → решение владельца (20.11.2026); крайние состояния.
