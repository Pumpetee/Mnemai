## Как выпускать (по просьбе владельца)

1. `git status` чистый, `main` синхронизирован с `origin`.
2. Тесты и линтеры: `python3 -m unittest discover -s tests -p "test_*.py"`, `ruff check`, `prettier`.
3. Версия: поднять `mnema/__init__.py`, один коммит `Mnemai X.Y.Z` с текстом для тега.
4. Тег и пуш: `git tag -a vX.Y.Z -F notes.txt` и `git push origin main vX.Y.Z`; workflow соберёт и
   опубликует релиз.
5. Проверить GitHub Actions и файлы релиза.
6. Дописать в этот файл тег и коммит, перенести пункты из «не выпущено» в историю.
