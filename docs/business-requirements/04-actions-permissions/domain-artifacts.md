# BP-04.4. Артефакты предметной области: действия и разрешения

Процесс BP-04 каталога процессов; основание — требования владельца (глоссарий, разделы 2, 3, 9, 10).
Сущности действий и разрешений, их состояния и переходы, правила процесса и словарь терминов. Механика
инструментов, журнала, памяти, файлов и приватности не дублируется — ссылки на BP-02, BP-05, BP-06, BP-07,
BP-11, BP-12 и темы 4.1, 4.2, 4.8. Пробелы источников — BP-04.1, раздел 7.

## 1. Модель состояний действия

```
Модель просит действие (триггер BP-04)
        │
        ├─ тумблер выключен ──► без вопроса (BP-04, шаг 1)
        ├─ тумблер включён ──► карточка «Да / Нет / Да для этого разговора» (ждать «да» ≤ 600 с)
        │        ├─ «Да» ──► выполнить один раз
        │        ├─ «Нет» ──► отклонено
        │        └─ «Да для этого разговора» ──► в список разрешённых действий чата; выполнить (допущение: включает «да» — выполнение текущего действия прямо не описано)
        ├─ вызов внешнего MCP-инструмента / проверочный прогон ──► отдельное «да» всегда (BP-04, шаг 2)
        ├─ sudo ──► пароль администратора один раз, нигде не сохраняется (BP-04, шаг 3)
        ├─ запрещённый путь (тема 4.1) ──► отклонено всегда, ни при каком разрешении
        ├─ лимиты: в чате до 12 (инструкцией модели); на шаге схемы — жёсткий стоп при более чем 80;
        │   3 одинаковых подряд (одинаковость — с учётом аргументов) ──► «цикл»; «да» ≤ 600 с,
        │   иначе — действие отменяется и генерация останавливается (BP-04, шаг 5)
        ▼
Исполняется (записи — в журнал) ──► Выполнено ──► Отменено (через «Историю», BP-07, BP-11)
        │
        ▼
Результат (выполнение или отклонение) возвращён модели (результат BP-04)
```

| «Да для этого разговора» | Ждёт решения → в список чата → Исполняется (допущение: включает «да» — выполнение текущего действия прямо не описано) | BP-04, шаг 2; FR-04; UC-02, 3в |

## 2. Сущности, состояния и переходы

### 2.1 Действие (запрос действия / инструмент)

| Поле | Значение |
|---|---|
| Определение | Операция, которую ИИ просит выполнить: файлы, команды, веб, память, задачи, рабочий стол (глоссарий требований); исполняется по правилам BP-04 в чате и на шагах схем (требования, разделы 2 и 10) |
| Атрибуты | Инструмент из каталога (2.5, FR-01); разряд обязательного вопроса: вызов внешнего MCP-инструмента, проверочный прогон (FR-05); требование прав администратора (sudo, FR-06); счётчик одинаковых повторов подряд — одинаковость с учётом аргументов (FR-10); счётчик действий на ответ/шаг (FR-09); запрещённый путь (2.6, FR-12) |
| Состояния | Запрошено → Ждёт решения (карточка) / Исполняется → Выполнено; Отклонено («Нет», запрещённый путь, «цикл», лимит); Отменено (через «Историю» после выполнения) |
| Переходы | См. модель состояний (раздел 1); результат выполнения или отклонения возвращается модели (FR-07) |

### 2.2 Разрешение (карточка)

| Поле | Значение |
|---|---|
| Определение | Карточка с кнопками «Да / Нет / Да для этого разговора», показываемая при включённом тумблере разрешений (требования, раздел 2; BP-04, шаг 1); для вызовов внешних MCP-инструментов и проверочных прогонов показывается всегда (BP-04, шаг 2) |
| Атрибуты | Ровно три кнопки (FR-03); срок ожидания решения — не более 600 с (FR-11); обязательность показа независимо от тумблера (FR-05) |
| Состояния | Показана → Решена («Да» / «Нет» / «Да для этого разговора»); Просрочена (600 с → действие отменено, генерация остановлена) |
| Переходы | Показать (FR-02, FR-03, FR-05); решить (FR-03, FR-04); отменить по таймауту (FR-11) |

### 2.3 Решение пользователя

| Поле | Значение |
|---|---|
| Определение | Ответ пользователя на карточку разрешения: «Да», «Нет» или «Да для этого разговора» (требования, раздел 2; BP-04, шаги 1–2) |
| Значения | «Да» — выполнить действие один раз; «Нет» — отклонить; «Да для этого разговора» — занести действие в список разрешённых действий этого разговора и выполнять без вопроса в пределах этого чата (требования, раздел 2; FR-03, FR-04) |
| Правила | «Да для этого разговора» действует только в пределах чата (FR-04); вызовы внешних MCP-инструментов и проверочные прогоны принимают только отдельное «да» и в список разговора не попадают (FR-05); «да» ожидается не более 600 с, при истечении действие отменяется и генерация останавливается (FR-11) |

### 2.4 Список разрешённых действий разговора

| Поле | Значение |
|---|---|
| Определение | Список действий чата, на которые пользователь ответил «Да для этого разговора» (требования, раздел 2 — «список … чата») |
| Атрибуты | Принадлежит одному чату (FR-04); в него не попадают вызовы внешних MCP-инструментов и проверочные прогоны (требования, раздел 2; FR-05) |
| Состояния | Пуст → Пополнен («Да для этого разговора»); в другом чате не действует (FR-04) |
| Переходы | Пополнить (FR-04); действие из списка выполняется в этом чате без карточки (FR-04) |
| Идентификаторы | Элементы списка — действия каталога; системные id генерирует система (каталог, раздел 1); человекочитаемых кодов нет (BP-04.1, раздел 6) |

## 3. Правила процесса

- **Правило тумблера.** Выключен — действие выполняется сразу, отмена в «Истории»; включён — карточка
  «Да / Нет / Да для этого разговора»; тумблер настраивается в BP-12, применяет его BP-04 (BP-04, шаг 1;
  BR-02, BR-03, BR-12).
- **Правило обязательного вопроса.** Вызовы внешних MCP-инструментов и проверочные прогоны — отдельное
  «да» всегда, при любом положении тумблера; в список разрешённых действий разговора не попадают (BP-04,
  шаг 2; BR-05).
- **Правило «Да для этого разговора».** Действует только в пределах чата (BR-04; FR-04).
- **Правило sudo.** Пароль администратора — один раз; не попадает ни в файл чата, ни в запросы модели
  (BP-04, шаг 3; BR-06).
- **Правило журнала.** Каждая запись действия направляется в журнал и отменяема через «Историю»; механика —
  BP-07, BP-11 (BP-04, шаг 4; BR-07).
- **Правило лимитов.** В чате до 12 действий на ответ — задано инструкцией модели, жёсткого счётчика нет;
  на шаге схемы — жёсткий стоп при более чем 80 действиях с сообщением; три одинаковых действия подряд
  (одинаковость — с учётом аргументов) — остановка с причиной «цикл»; ожидание «да» — не более 600 с,
  при истечении действие отменяется и генерация останавливается (BP-04, шаг 5; BR-08; требования,
  раздел 10; тема 4.8; решение владельца — 20.11.2026).
- **Правило deny-list.** Запрещённые пути недоступны ни при каком разрешении; расширение — только с явного
  разрешения пользователя и после ревью (BP-04, шаг 6; BR-09; требования, раздел 9; тема 4.1).
- **Правило прогона.** Полный проверочный прогон — в безопасной приватной временной папке: тестовые записи
  помечаются и удаляются, буфер обмена восстанавливается, инструменты рабочего стола пропускаются; «да» —
  всегда (BP-04, шаг 7; BR-10; требования, раздел 3).
- **Правило каталога.** Модели доступен каталог 56 инструментов указанных групп, не считая служебного
  списка (границы BP-04; BR-11; требования, раздел 3).
- **Правило результата.** Исход действия — выполнение или отклонение — возвращается модели (результат
  BP-04; BR-07).
