# BP-08.4. Артефакты предметной области: обучение из источников

Процесс: BP-08 каталога бизнес-процессов; основание — человеко-требования (разделы «Термины и роли», «Обучение», «Приватность и безопасность», «Ограничения», «Краевые состояния и отказы»). Сущности, их состояния и переходы, правила процесса и словарь терминов. Механика записи в память, журнала, прав доступа и настроек не дублируется — ссылки на BP-07, BP-12, BP-16 и темы 4.1, 4.2.

## 1. Модель состояний конвейера обучения

```
Таймер обучения / новое сообщение в чате (триггер BP-08)
        │
        ▼
Чтение источников: только включённые и разрешённые (FR-02)
  ├─ Telegram — строго чтение, только выбранные чаты (FR-01, FR-04)
  └─ офлайн → пауза сетевых источников (FR-14)
        │
        ▼
Эпизоды (FR-05) → Разбор: способ по типу источника — Telegram: сигналы, файлы/веб: локальная модель (FR-06)
        │
        ▼
Факты-кандидаты (FR-06) → Журнал уверенности: повторы ↑ уверенность, день said_at (FR-07)
        │
        ▼
Решение: записать / спросить / подождать / пропустить — причина в фиде (FR-08)
  ├─ уверенность ≥ порога (по умолчанию 0.8) → записать сразу (FR-09)
  ├─ личное → только скрытые карточки (FR-10)
  ├─ разговор в Mnemai: личное/противоречие → один вопрос под разговором, ответы «Да / Нет» (FR-11)
  └─ запись факта → по правилам BP-07 (FR-13)
        │
        ▼
Фид «Что я понял и почему» — решения с причинами (FR-08)
Отмена выученного = «нет» навсегда (FR-12)
```

(Решения владельца: интервал таймера — раз в час; способ разбора — по типу источника; ответы на вопрос —
«Да / Нет».)

| Переход | Откуда → куда | Правило |
|---|---|---|
| Чтение источника | — → Эпизоды | Только включённые и разрешённые — BP-08, шаг 1; FR-02 |
| Telegram | — → Чтение (только чтение) | раздел «Ограничения»; тема 4.1; FR-04 |
| Офлайн | Чтение → Пауза | BP-08, шаг 7; раздел «Краевые состояния и отказы»; FR-14 |
| Разбор | Эпизоды → Факты-кандидаты | BP-08, шаг 2; FR-06 |
| Повтор | Кандидат → уверенность выше | BP-08, шаг 2; FR-07 |
| Решение | Кандидат → Решён | BP-08, шаг 3; FR-08 |
| Автозапись | Решён («записать») → Факт записан | Порог ≥ 0.8 по умолчанию — BP-08, шаг 4; FR-09; запись — BP-07 (FR-13) |
| Личное | Кандидат → Скрытые карточки | BP-08, шаг 4; FR-10; тема 4.1 |
| Вопрос | Разговор в Mnemai → Вопрос под разговором | BP-08, шаг 5; FR-11 |
| Отмена | Факт записан → «Нет» навсегда | BP-08, шаг 6; FR-12; тема 4.2 |

## 2. Сущности, состояния и переходы

### 2.1 Источник

| Поле | Значение |
|---|---|
| Определение | Источник обучения: AI-чаты, заметки, почта, Telegram (только выбранные чаты), Obsidian, календарь, документы, история браузера (раздел «Обучение») |
| Атрибуты | Тип источника; включён/выключен; разрешение (каждое — отдельное — BP-08, шаг 1); для Telegram — выбранные чаты (раздел «Обучение») |
| Состояния | Не разрешён → Разрешён; выключен / включён (настройка — BP-12, ссылка) |
| Переходы | Выдача и отзыв разрешений — BP-12 (ссылка); чтение — только включённых и разрешённых (FR-02) |
| Ограничение | Telegram — строго чтение (раздел «Ограничения»; FR-04); логин Telegram — по правилам темы 4.1 (FR-16) |

### 2.2 Эпизод

| Поле | Значение |
|---|---|
| Определение | Порция прочитанного из источника, идущая на разбор (раздел «Обучение») |
| Атрибуты | Источник; место происхождения (сверка фактов: источник, ссылка, время, текст — архитектурное описание «Обучение») |
| Состояния | Прочитан → Разобран |
| Переходы | Формирование из прочитанного (FR-05); разбор → кандидаты (FR-06) |

### 2.3 Факт-кандидат

| Поле | Значение |
|---|---|
| Определение | Догадка о факте, полученная при разборе эпизода, до решения (раздел «Обучение») |
| Атрибуты | Текст; уверенность (FR-07); день «said_at» (FR-07); признак личной темы (FR-10) |
| Состояния | Кандидат → Решён (записать / спросить / подождать / пропустить — FR-08); Ожидает (подождать — FR-09); «Нет» навсегда (после отмены — FR-12) |
| Переходы | Повтор → уверенность выше (FR-07); решение (FR-08); запись → BP-07 (FR-13); отмена выученного → «нет» навсегда (FR-12) |

### 2.4 Журнал уверенности (ledger)

| Поле | Значение |
|---|---|
| Определение | Журнал по кандидатам: повторения повышают уверенность; хранится день, когда сказано (`said_at`) (раздел «Обучение») |
| Атрибуты | Уверенность кандидата; день «said_at» |
| Состояния | Пополняется повторами (FR-07) |
| Переходы | Повтор упоминания → уверенность выше (FR-07); достижение порога → автозапись (FR-09) |

### 2.5 Решение

| Поле | Значение |
|---|---|
| Определение | Итог по кандидату: записать / спросить / подождать / пропустить — с причиной (раздел «Обучение») |
| Атрибуты | Одно из четырёх значений; причина (показывается в фиде — FR-08) |
| Состояния | Принято → отражено в фиде |
| Переходы | Принятие решения (FR-08); исполнение: запись — BP-07 (FR-13), вопрос — FR-11, ожидание — FR-09, пропуск |
| Примечание | Перечень текстов причин фида в источниках не задан (допущение: причина — пояснение выбора; конкретные формулировки уточняются при ревизии раздела «Обучение») |

### 2.6 Фид

| Поле | Значение |
|---|---|
| Определение | Лента «Что я понял и почему» — решения обучения с причинами (раздел «Термины и роли» «Фид»; раздел «Обучение») |
| Атрибуты | Решения с причинами (FR-08) |
| Состояния | Пополняется каждым решением; пустой до первого решения (UC-07, А1 — допущение) |
| Переходы | Каждое решение → запись в фиде (FR-08) |

### 2.7 Настройки обучения (владение — BP-12, ссылка)

| Поле | Значение |
|---|---|
| Интервал таймера | Раз в час (раздел «Обучение» «по таймеру»; FR-03; решение владельца) |
| Порог автозаписи | `auto_confidence`, по умолчанию 0.8 (80 %) (раздел «Обучение»; FR-09) |
| Кулдаун повторного вопроса | Настройка, ограничивающая повторные вопросы (раздел «Обучение»; FR-11) |
| Порог уверенности | Настройка, учитываемая при вопросе под разговором (раздел «Обучение»; FR-11) |
| Примечание | Настройка значений — BP-12; BP-08 использует результат (FR-09, FR-11) |

## 3. Правила процесса

- Читаются только включённые и разрешённые источники, по таймеру раз в час; каждое разрешение отдельное
  (BP-08, шаг 1; FR-01, FR-02, FR-03; решение владельца).
- Telegram — строго чтение, только выбранные чаты (BP-08, граница; раздел «Ограничения»; FR-01, FR-04).
- Конвейер: источники → эпизоды → разбор способом по типу источника (Telegram — сигналы, файлы и веб —
  локальная модель) → факты-кандидаты → журнал уверенности → решение (BP-08, шаг 2; FR-05, FR-06,
  FR-07; решение владельца).
- Повторения повышают уверенность; хранится день «said_at» (BP-08, шаг 2; FR-07).
- Решение по кандидату — одно из четырёх, с причиной в фиде (BP-08, шаг 3; FR-08).
- Уверенность ≥ порога (по умолчанию 0.8) → записать сразу; ниже — ждать повторения (BP-08, шаг 4;
  FR-09; настройка порога — BP-12).
- Личное (деньги, здоровье, приватное) — только в скрытые карточки (BP-08, шаг 4; FR-10; тема 4.1).
- Из разговора в Mnemai личное или противоречие — один вопрос с ответами «Да» (записать) и «Нет» (не
  записывать) под разговором, с кулдауном и порогом; «спросить один раз» не гарантируется (BP-08,
  шаг 5; FR-11; решение владельца).
- Отмена выученного = «нет» навсегда (BP-08, шаг 6; FR-12; тема 4.2).
- Запись фактов — по правилам BP-07 (BP-08, шаг 6; FR-13).
- В офлайне — пауза сетевых источников (BP-08, шаг 7; FR-14; тема 4.8).
- Достижения начисляются в обучении (тема 4.6; FR-15).
- Человекочитаемые коды в процессе не используются: в источниках не описаны (раздел 6 каталога);
  системные id генерирует система (раздел 1 каталога).

выводятся из раздел «Обучение», раздел «Ограничения» и раздел «Краевые состояния и отказы».

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | раздел «Термины и роли» (дословно) |
| Провайдер | Источник ИИ: подписка Claude (Claude Code), подписка ChatGPT (Codex), ключ API, локальная модель, Harness-агент; разбор эпизодов использует Claude Code, ключ API или локальную модель | раздел «Термины и роли» (дословно); раздел «Обучение» |
| Клиент | Правило доступа: какие части памяти и с какими правами видит конкретный ИИ; скрытые карточки — тема 4.1 | раздел «Термины и роли» |
| Скоуп | Раздел памяти: профиль, правила, проекты, карточки, люди, решения, входящие, заметки | раздел «Термины и роли» (дословно) |
| Фид | Лента «Что я понял и почему» — решения обучения с причинами | раздел «Термины и роли» (дословно) |
| Источник обучения | AI-чаты, заметки, почта, Telegram (только выбранные чаты), Obsidian, календарь, документы, история браузера | раздел «Обучение» |
| Эпизод | Порция прочитанного из источника, идущая на разбор | раздел «Обучение»; сверка фактов — архитектурное описание «Обучение» |
| Разбор (brain) | Обработка эпизодов способом по типу источника (Telegram — сигналы, файлы и веб — локальная модель) → факты-кандидаты | раздел «Обучение»; решение владельца |
| Факт-кандидат | Догадка о факте до решения | раздел «Обучение» |
| Журнал уверенности (ledger) | Повторения повышают уверенность; хранится день, когда сказано (`said_at`) | раздел «Обучение» |
| Порог автозаписи | Настройка `auto_confidence`, по умолчанию 0.8 (80 %): на уровне порога факт записывается сразу | раздел «Обучение» |
| Кулдаун повторного вопроса | Настройка обучения, ограничивающая повторные вопросы под разговором | раздел «Обучение» |
| Таймер обучения | Чтение источников раз в час | раздел «Обучение» «по таймеру»; решение владельца |
| Ответ на вопрос под разговором | «Да» — факт записывается, «Нет» — запись не выполняется | Решение владельца |
| Скрытые карточки | Карточки памяти для личного (деньги, здоровье, приватное); скрытие — тема 4.1 | раздел «Обучение» |
| Противоречие | Находка, противоречащая памяти; спрашивается под разговором | раздел «Обучение» |
| Отмена выученного | «Нет» навсегда: факт больше не предлагается и не записывается | раздел «Обучение» |

## 5. Идентификаторы и коды

- Системные id генерирует система (правило каталога, раздел 1).
