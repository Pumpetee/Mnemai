# BP-12.4. Артефакты предметной области: настройки

Сущности настроек: подключения ИИ, пресеты, правила общения, доступы, настройки обучения, VPN,
язык/тема/автозапуск/трей, точки входа в смежные процессы. Механика VPN, хранения секретов, шифрования,
провайдеров и локализации не дублируется — ссылки на BP-01, BP-04, BP-07, BP-08, BP-15, BP-16 и темы 4.1,
4.3, 4.5, 4.7, 4.8. Факты, которые вводные не задают, отмечены ссылкой на BP-12.1 («Область вне
требований») или словом «допущение» — и в диаграмме, и в таблицах.

## 1. Модель состояний настройки

```
Пользователь открывает настройки (триггер BP-12)
        │
        ▼
Просмотр разделов: ИИ и модели / движок / правила / память / приватность / VPN / язык / тема /
автозапуск / трей (BP-12, шаги 1–7)
        │ пользователь меняет настройку
        ▼
Изменено ──► проверка: подключения — по теме 4.3 (FR-03); VPN — автодетект или ключ (FR-10; тема 4.1)
        ├─ проверка не прошла ──► причина показана; настройка не применена (тема 4.3; FR-03)
        │        [неудачный автодетект/неверный ключ — ошибка и предложение ввести ключ вручную (FR-10)]
        └─ проверка прошла / проверка не требуется ──► Сохранено и применено в чате, обучении,
                инструментах и интерфейсе (результат BP-12; FR-01)
                [применяется сразу, без перезапуска — допущение, BP-12.1, «Область вне требований»]

Точки входа в смежные процессы (из настроек):
        ├─ возврат к шагу онбординга ──► BP-01, шаг 5 (FR-15)
        ├─ включение пароля шифрования ──► BP-15, «Триггер» (FR-16)
        ├─ удаление секрета ──► BP-16, шаг 4 (FR-17)
        ├─ дополнительная папка ──► BP-07, шаг 8 (FR-09)
        ├─ порог автозаписи/кулдаун ──► BP-08, шаги 4–5 (FR-08)
        └─ тумблер разрешений ──► BP-04 (FR-07)
```

| Переход | Откуда → куда | Правило |
|---|---|---|
| Открытие настроек | — → Просмотр разделов | Триггер BP-12 |
| Изменение настройки | Просмотр → Изменено | BP-12, шаги 1–7; FR-02…FR-14 |

| Сохранение и применение | Изменено → Сохранено и применено (чат, обучение, инструменты, интерфейс) | Результат BP-12; FR-01 (сразу, без перезапуска — допущение) |

| Подключение по ключу | Изменено → Подключён (ключ/ссылка-подписка) | BP-12, шаг 5; FR-10; тема 4.1 |

## 2. Сущности, состояния и переходы

### 2.1 Настройка

| Поле | Значение |
|---|---|
| Определение | Параметр приложения, который пользователь меняет в «Настройках»; изменения сразу применяются в чате, обучении и инструментах (назначение BP-12) |
| Атрибуты | Раздел (2.2–2.15); значение; место применения: чат / обучение / инструменты / интерфейс (результат BP-12) |
| Состояния | Значение по умолчанию → Изменено → Сохранено и применено |
| Переходы | Изменение (FR-02…FR-14); сохранение и применение (FR-01) |
| Допущение | Применяется сразу, без перезапуска; какие настройки требуют перезапуска — не описано (BP-12.1, «Область вне требований») |

### 2.2 Подключение ИИ (провайдер)

| Поле | Значение |
|---|---|
| Определение | Источник ИИ, подключаемый в настройках: подписка Claude (Claude Code), подписка ChatGPT (Codex), ключ API, локальная модель (встроенная, Ollama, Strata), Harness-агент (словарь терминов; описание чата; BP-12, шаг 1) |
| Атрибуты | Тип (описание чата); данные подключения (ключ — хранение: тема 4.1, BP-16); списки моделей (тема 4.3) |
| Состояния | Не подключён → Подключён → Проверен (работает) / Нерабочий (причина: упал / лимит / нет денег / ключ отклонён — тема 4.3) |
| Переходы | Подключение (FR-02); проверка (FR-03); нерабочий не попадает в списки моделей (FR-03; тема 4.3); удаление ключа — BP-16 (FR-17) |
| Примечание | Подключение первого ИИ после визарда — BP-01; использование — BP-02, BP-03, BP-06 (тема 4.3) |

### 2.3 Пресет движка

| Поле | Значение |
|---|---|
| Определение | Набор параметров движка, выбираемый целиком: «Быстрый», «Сбалансированный», «Качественный» (BP-12, шаг 2; «пресеты» — сверка с описанием клиентского пути (настройки); решение владельца, 20.11.2026) |
| Атрибуты | Название из набора «Быстрый» / «Сбалансированный» / «Качественный»; параметры движка; числа лимитов — в продвинутом разделе (решение владельца, 20.11.2026; тема 4.8; действующие лимиты) |
| Состояния | Выбран → Применён |
| Переходы | Выбор и применение (FR-04) |
| Примечание | Конкретные значения чисел лимитов — целевые показатели, подтверждаются замерами |

### 2.4 Правило общения

| Поле | Значение |
|---|---|
| Определение | Правило каталога с тумблером по теме: как говорить, работа с задачей, факты, память, приватность, оформление (описание чата; BP-12, шаг 3) |
| Атрибуты | Тема (одна из шести); тумблер (включено/выключено) |
| Состояния | Выключено → Включено |
| Переходы | Переключение тумблера (FR-05); включённые правила участвуют в сборке ответа (BP-02, шаг 2) |
| Пробел | Полный перечень правил внутри тем и значения по умолчанию не приведены (BP-12.1, «Область вне требований») |

### 2.5 Доступ ИИ (клиент)

| Поле | Значение |
|---|---|
| Определение | Права конкретного ИИ на части памяти: чек-боксы чтения/записи по скоупам и скрытые теги с замком на тему (словарь терминов; приватность и безопасность; BP-12, шаг 4) |
| Атрибуты | Скоупы чтения; скоупы записи; скрытые теги (`#money`/`#health`/`#private` — описание памяти); замок на тему (приватность и безопасность) |
| Правила | Задаётся в настройках (FR-06); применяется едино для чата и внешних MCP-клиентов (тема 4.1); локальная модель видит всё — с компьютера ничего не уходит (приватность и безопасность) |
| Состояния | Задан → Применяется (BP-02, BP-07) |
| Примечание | Скрытые разделы профиля, скрытые теги и факт-архив модели не получают (тема 4.1; BP-07) |

| Правила | Поведение тумблера — BP-04; вызовы внешних MCP-инструментов и проверочные прогоны спрашивают «да» всегда (BP-04, шаг 2; описание чата) |

## 3. Правила процесса

- **Правило сохранения и применения.** Изменения настроек сохраняются и сразу применяются в чате,
  обучении, инструментах и интерфейсе (результат BP-12; BR-01; FR-01; без перезапуска — допущение).
- **Правило проверки подключений.** Подключение проверяется; нерабочий провайдер получает причину,
  помечается и не попадает в списки моделей (BP-12, шаг 1; BR-02; FR-03; тема 4.3).
- **Правило пресетов.** Движок настраивается через пресеты «Быстрый», «Сбалансированный»,
  «Качественный»; числа лимитов — в продвинутом разделе; действующие лимиты — тема 4.8 (BP-12, шаг 2;
  BR-03; FR-04; решение владельца, 20.11.2026).
- **Правило каталога правил.** Правила общения — каталог с тумблерами по шести темам; включённые правила
  участвуют в сборке ответа (BP-12, шаг 3; BR-04; FR-05; BP-02).
- **Правило доступов.** Доступы ИИ задаются чек-боксами по частям памяти и замком на тему; правило едино
  для чата и MCP; локальная модель видит всё (BP-12, шаг 4; BR-05; FR-06; приватность и безопасность;
  тема 4.1).
- **Правило тумблера разрешений.** Тумблер разрешений — настройка BP-12; по умолчанию выключен; поведение
  — BP-04 (BP-12, шаг 4; BR-06; FR-07; описание чата).
- **Правило обучения.** Порог автозаписи (по умолчанию 0.8) и кулдаун (по умолчанию 10 минут) задаются в
  BP-12; применение — BP-08 (BP-12, шаг 4; BR-07; FR-08; описание обучения).
- **Правило дополнительных папок.** Дополнительные папки подключаются в настройках; только чтение —
  BP-07 (BP-12, «Входит»; BR-08; FR-09; описание памяти).
- **Правило VPN.** Автодетект (Windows) или VPN-ключ/ссылка-подписка; прокси только для Mnemai; при
  неудачном автодетекте или неверном ключе — ошибка и предложение ввести ключ вручную; механика и
  хранение ключа — тема 4.1, BP-16 (BP-12, шаг 5; BR-09; FR-10; приватность и безопасность).
- **Правило языка.** Девять языков интерфейса; язык общения — в профиле; ответы следуют языку (BP-12,
  шаг 6; BR-10; FR-11; приложение и жизненный цикл; тема 4.5).
- **Правило темы и автозапуска.** Тема светлая/тёмная; автозапуск — опция (BP-12, шаг 7; BR-11; FR-12,
  FR-13; приложение и жизненный цикл).
- **Правило трея.** Иконка в трее; поведение — тема 4.7 (BP-12, «Входит»; BR-12; FR-14; приложение и
  жизненный цикл).
- **Правило точек входа.** Из настроек доступны шаги онбординга (BP-01), включение пароля (BP-15) и
  удаление секретов (BP-16); правила поведения — у этих процессов (BR-13; FR-15, FR-16, FR-17).

## 5. Идентификаторы и коды

- Системные id генерирует система (общее правило каталога).
- Человекочитаемые коды, вводимые пользователем, в BP-12 отсутствуют: в источниках они не описаны
  («Область вне требований» каталога). Если такие коды появятся — проверка уникальности по общему
  правилу каталога.
- Названия настроек (`auto_confidence` — описание обучения) — внутренние, пользователем не вводятся.
