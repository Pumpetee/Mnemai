Mnemai

Mnemai — локальное desktop-приложение (Windows, macOS, Linux): память человека как папка Markdown на его компьютере, подключение ИИ и инструменты для них с разрешениями.
Подключает ИИ: подписки Claude и ChatGPT, ключи API (Anthropic, OpenAI, Gemini, DeepSeek, OpenRouter, YandexGPT, OpenCode Go), локальные модели (встроенная, Ollama, Strata), DeepSeek Harness-агент.
Собственного облака и аккаунта нет: облако — только вызовы выбранных пользователем ИИ; единственный сервер — необязательная станция самого пользователя.
Станция — личный сервер владельца; доступ по паролю, роли не вводятся.
Память — папка Markdown (по умолчанию ~/Mnemai): 00 Inbox, 10 Now, 20 Projects, 30 People, 60 Events, 70 Memory (Profile, Rules, Thoughts, Cards, Fact archive), 90 System (Journal, Recipes), 95 Saves, .mnema (права, журнал со снапшотами, токен, обучение, чаты).
Факт — одна строка с датой; новый статус заменяет старый, старый уходит в факт-архив, изменение — в ленту событий; факт-архив модели не получают никогда.
Index собирается автоматически из заметок и руками не правится.
Портрет — 2–3 предложения вверху Profile: первое, что читает каждый ИИ; пополняется обучением, правится руками.
Карта памяти: темы-пузыри (размер — сколько Mnemai знает), пульс у недавно изменённых, замок у скрытых тем (#money, #health, #private); карточки тем детализированы.
Статусы старше 30 дней переспрашиваются, а не подаются как текущие; переспрос — вопрос в чате при первом упоминании темы.
Журнал каждого чтения и записи + undo («Память → История»); «откуда я это знаю» — ссылка на источник факта; экспорт журнала (Markdown/JSON) и ротация: порог 10 МБ, хранится 5 архивов.
Дополнительные папки (Obsidian-хранилища, командные папки) — только чтение, запись блокируется; авторизация командных папок не вводится.
Чат: ответ строится из правил общения (каталог с тумблерами), видимой этой модели памяти, живого описания «как Mnemai устроена сейчас» и нужных частей базы знаний.
В чате: стриминг ответа, stop / redo / regenerate, сессии и список чатов, экспорт чата в Markdown, импорт из ChatGPT, рецепты задач.
Действия в чате: до 12 на ответ; тумблер разрешений по умолчанию выключен — действия выполняются сразу, отмена в «Истории»; включён — карточка «Да / Нет / Да для этого разговора».
«Да для этого разговора» действует в пределах чата; mcp_call спрашивает одно «да» на вызов, но «Да для этого разговора» разрешает его на весь разговор; проверочные прогоны mcp_smoke* спрашивают «да» всегда, по одному на каждый прогон (FORCE_ASK).
Пароль администратора (sudo) в чате спрашивается один раз и не попадает ни в файл чата, ни модели.
Каталог инструментов — 56 (не считая служебного списка, на 18.11.2026): память, файлы, команды, веб, задачи, буфер обмена, уведомления, снимок экрана, фоновые задачи, субагенты.
Лимиты: один вызов провайдера — не более 300 с; в чате «до 12 действий на ответ» задано инструкцией модели, жёсткого счётчика нет; на шаге схемы — жёсткий стоп при более 80 действиях с сообщением «Слишком много действий подряд — шаг остановлен…»; действие, на которое владелец не ответил за 600 с, отменяется, генерация останавливается; live-статусы обновляются каждые 200 мс.
Deny-list: .ssh, .gnupg, .aws, keyring и секретные хранилища браузеров недоступны файловым инструментам; команды с этими путями отклоняются.
Внешние MCP-клиенты (Claude Code, Claude Desktop, Cursor): отдельный MCP-сервер поверх stdio, у каждого клиента свои права чтения/записи и скрытые теги.
Цель (решение 18.11.2026): «вся программа и есть MCP» — весь инструментальный слой доступен как MCP-инструменты, ИИ подключаются только своим MCP-клиентом; блоки вызова инструментов в чате остаются до полного перехода.
Сторонние MCP-серверы как источники инструментов не поддерживаются — только собственный MCP-сервер Mnemai.
При заблокированной памяти внешние MCP-клиенты получают отказ с запросом пароля (как в приложении); офлайн — только локальные модели.
Конструктор схем: по описанию задачи планировщик подбирает шаги и исполнителей из подключённых ИИ и даёт три варианта (Быстро / Оптимально / Качественно) с оценкой времени, токенов и цены.
Длина цепочки — до 6 шагов, вариант «Качественно» — до 5; бюджет рекомендуемый (из дешёвой сметы) или свой, в долларах.
Все варианты укладываются в бюджет: дорогие шаги понижаются до дешёвых моделей; если не влезает — честно показан минимум; экономия включена всегда, выключить её нельзя.
Оценка времени и токенов — по таблице средних показателей моделей; «окупается» — не дороже 2× цены дешёвого шага.
Шаги схемы можно править до запуска; при закрытии окна цепочка продолжается в фоне.
Цены: точные — только для OpenRouter (публичный каталог); у остальных — ориентир по имени модели, может расходиться.
Запуск цепочки в чате: live-статусы шагов, остановка пользователем с понятной причиной, защита от цикла (одно и то же действие с теми же аргументами 3 раза подряд), фолбэк при сбое провайдера.
Обучение: источники — AI-чаты, заметки, почта, выбранные чаты Telegram, Obsidian, календарь, документы, история браузера; каждый источник — отдельное разрешение; читаются по таймеру — раз в час.
Telegram — строго чтение.
Конвейер обучения: источники → эпизоды → разбор (явные сигналы, Claude Code, ключ API, локальная модель) → факты-кандидаты → журнал уверенности (повторы повышают) → решение (записать / спросить / подождать / пропустить) с причиной в фиде «Что я понял и почему»; способ разбора выбирается по типу источника.
Порог автозаписи — auto_confidence, по умолчанию 0.8 (80%); личное (деньги, здоровье, приватное) — только в скрытые карточки.
Из разговора в Mnemai личное или противоречие спрашивается под разговором: варианты ответа «Да / Нет», кулдаун повторного вопроса — по умолчанию 10 минут, порог уверенности; «спросить один раз» не гарантируется; отмена выученного — «нет» навсегда.
«Знакомство» (интервью) запускается автоматически при первом знакомстве и повторно по кнопке; ответы становятся обычными фактами памяти.
Квиз «Насколько Mnemai тебя знает» показывает факты от простого к сложному; ответ «да / изменилось / нет» правит память; оба доступны как форма и API-команда.
Встречи: запись микрофона и звука компьютера двумя дорожками (видно, кто говорит); лимит записи — 5 часов.
Распознавание: Whisper локально (бесплатно) или облачный Whisper (цена внешнего сервиса на дату, ориентир ≈ $0.36/час); тишина, фразы-ошибки и эхо вырезаются; лимит 300 с к облачному распознаванию не применяется.
Пресеты встреч: Private / Quality / Fast задают весь путь сразу — Private: только локальные модели; Quality: облачное распознавание при наличии ключа, иначе локально (пресет по умолчанию); Fast: короткие записи локально, длинные — в облако; точный список моделей определяется установленными локальными моделями и подключёнными провайдерами; итог — решения, задачи и их владельцы — любым ИИ, включая локальный.
Голосовая команда распознаётся на компьютере и отправляется в чат сообщением; голос, OCR и распознавание речи работают одинаково на всех трёх ОС.
Файлы: вложения — форматы PDF/Word/Excel/изображения/текст, до 100 МБ; сканы и картинки распознаются локально (OCR); создание PDF/Word/Excel; merge / split / поворот PDF; созданные документы — в Saves и показываются в чате; каждая запись отменяется через журнал.
Экономия токенов: документы, память и веб-страницы читаются на компьютере, модели уходят только релевантные части; под ответом — сколько токенов сэкономлено.
Настройки: ИИ и модели, движок и лимиты, правила общения с тумблерами (как говорить, работа с задачей, факты, память, приватность, оформление), память, приватность, язык, тема.
Доступы: чек-боксы по частям памяти, замок на тему; локальная модель видит всё — с компьютера ничего не уходит.
VPN: автопоиск рабочего VPN пользователя без ввода данных (Windows — локальные прокси-клиенты) либо подключение по VPN-ключу или ссылке-подписке через встроенный механизм; локальный прокси только для Mnemai, система не трогается; ключ — в защищённом хранилище системы; при неудачном автодетекте — ошибка и предложение ввести ключ вручную.
Девять языков интерфейса; язык общения задаётся в профиле, ответы ИИ следуют ему; тема светлая/тёмная; автозапуск — опция.
Команды без модели (intents): «открой …» выполняются сразу, без вызова ИИ, одинаково на всех моделях; каталог сайтов фиксирован (Wikipedia, Google, Yandex, YouTube, GitHub, Habr, Stack Overflow, Кинопоиск — у каждого домашний URL и шаблон поиска); «открой этот сайт» открывает ссылку из сообщения или вложения в системном браузере; свои сайты пользователь не добавляет.
Консорциум: живая дискуссия 2–4 ИИ (совет, дебаты, мозговой штурм, ред-тим, roast); роли фиксированы — ведущий, участники, суммаризатор; тема консорциума — первое сообщение; «Стоп» — пауза с возможностью продолжить; спор под любым ответом.
Достижения: опыт, уровни, серии, бейджи (игровой слой).
Синхронизация: цели — Google Drive, Dropbox, произвольная папка (NAS/USB/другой облачный клиент) и станция (собственный сервер пользователя с копией памяти); запускается при старте, затем раз в 10 минут при изменениях и вручную; активна одна цель.
Уходят: заметки без генерируемых Now/Index и без локальных сейвов, чаты, правила доступа клиентов; никогда не уходят: ключи, токены, состояние обучения, настройки движка этого компьютера.
Конфликты — трёхстороннее слияние: остаётся версия этого компьютера, чужая сохраняется рядом как «<имя> (с другого устройства <дата>)» с уведомлением; при недоступности цели — повтор через 5 минут, индикатор в трее.
Шифрование: пароль → AES-256-GCM на 11 текстовых расширений (.md, .json, .jsonl, .txt, .csv, .tsv, .log, .yml, .yaml, .html, .htm); читаются только в приложении; скопированная или синхронизированная копия остаётся зашифрованной; ключевой материал производный от пароля.
Восстановление забытого пароля — только по recovery-ключу, который система показывает один раз при создании пароля; неверный пароль — «пароль не подходит», без ограничения попыток.
Смена пароля — в настройках, с перешифрованием; удаление пароля — с полной расшифровкой.
Бинарные файлы (PDF, картинки, записи) и служебные PLAIN-файлы не шифруются — зафиксировано «только текст-файлы», система предупреждает об этом в интерфейсе; опция EFS на Windows — отдельный механизм.
Обновления: проверка при каждом запуске и кнопка Update; источник — GitHub-релизы, канал стабильный, бета-каналов нет; установка по ОС (Windows — при выходе, Linux — замена AppImage и перезапуск, macOS — открытие .dmg с инструкцией в окне); целостность проверяется по контрольной сумме, при сбое проверки цикл пропускается без установки; откат — переустановка.
Онбординг (первый запуск): визард из 4 шагов — тема → язык → «как к тебе обращаться» → память (создать или открыть, опционально пароль); после визарда — подключение хотя бы одного ИИ и первый вопрос; к любому шагу можно вернуться через настройки; при закрытии приложения в середине визарда визард начинается заново при следующем запуске.
Данные: всё созданное пользователем (память, чаты, журнал, вложения) лежит на его компьютере; серверов у Mnemai нет.
Экспорт: память — открытыми Markdown-файлами (папкой), журнал — из «Память → История», чаты — из чата в Markdown; экспорт памяти при включённом шифровании запрещён.
Удаление: папка памяти удаляется после закрытия приложения и остановки синхронизации (отмены удаления папки нет); чат или факт — через интерфейс и журнал (undo); секреты (ключи API, логин Telegram, VPN-ключи) хранятся в защищённом хранилище системы отдельно от папки памяти и удаляются в настройках; в журналах секретов нет (только счётчики).
Вложения остаются в Saves; снапшот до первой правки дня (95 Saves) восстанавливается кнопкой «восстановить» в журнале; полная копия папки — на усмотрение пользователя или синхронизация.
Приватность: секреты (номера карт, пароли, ключи API, токены, телефоны, паспорт, СНИЛС) заменяются метками до отправки в облако и подставляются обратно в ответ.
Каждый облачный запрос логируется (когда, кому, зачем, сколько памяти из доступной, что скрыто — только счётчики); в облако уходят только текст сообщения, память в пределах скоупа выбранной модели, содержимое приложенных файлов и прочитанные веб-страницы.
Один экземпляр на пользователя; иконка в трее; выход останавливает обучение, трей и окно; при падении страница перезагружается сама (400/1500/4000/15000 мс, затем раз в минуту), неотправленный текст восстанавливается из черновика; сторож памяти окна раз в 30 с (пороги 1500/3000 МБ) — сейчас только Linux.
Краевые состояния: нет подключённых ИИ — чат не отправляет запрос и ведёт в настройки, память, журнал и команды без модели работают; офлайн — локальные модели, память, журнал, команды без модели и файлы работают, обучение из сетевых источников приостанавливается.
Провайдер упал / лимит / нет денег / ключ отклонён — сообщение с причиной, провайдер помечается нерабочим и не попадает в списки моделей; в схеме — фолбэк на другого исполнителя.
Память зашифрована и заблокирована (пароль не введён) — запросы, которым нужна память, отклоняются ошибкой блокировки, интерфейс предлагает ввести пароль.
Прерванный шаг цепочки (остановка, сбой провайдера, цикл) — шаг помечается с причиной, цепочка не «зависает» и не продолжается молча.
Целевые показатели (не SLA), подтверждаются замерами: первый токен ≤ 2 с (встроенная локальная модель 1–4B) и ≤ 5 с (облачная); холодный старт ≤ 5 с; лаг live-статусов ≤ 1 с; параллельные чаты ≥ 4; память на простое ≤ 400 МБ, рост не более 50 МБ за 10 минут.
Целевые показатели качества (подтверждаются замерами): каждая кнопка — проверочный сценарий «открыть → кликнуть → проверить», критерий выпуска — 0 «мёртвых» кнопок; каждая API-команда — тест контракта; покрытие ключевых модулей ≥ 80% (сейчас 649 тестов); полный набор тестов — не дольше 3 минут; ответы валидируются схемами (цель — сейчас схем нет).
Релизы выпускаются батчами; версия, тег и релиз — только по прямой просьбе пользователя (владельца).
Защита от prompt injection: явное правило не вводится — поведение остаётся как есть.
Эталон BRD получен (проект Lman): формат каталога, BP-XX.1 и BP-XX.2/3/4 зафиксирован — заголовки «# BP-XX.N. …», без временных шапок, хешей, vault-ссылок и §N; внутренняя структура сохраняется.

Определения
Пользователь (владелец) — человек, чья это память и компьютер.
Клиент — правило доступа: какие части памяти и с какими правами видит конкретный ИИ.
Провайдер — источник ИИ: подписка Claude, подписка ChatGPT, ключ API, локальная модель, Harness-агент.
Инструмент (действие) — операция, которую ИИ просит выполнить: файлы, команды, веб, память, задачи, рабочий стол.
Схема (план, цепочка) — набор шагов с исполнителями и бюджетом, который запускается в чате.
Консорциум — живая дискуссия 2–4 ИИ по одной теме.
Станция — необязательный собственный сервер пользователя с копией памяти.
Скоуп — раздел памяти: профиль, правила, проекты, карточки, люди, решения, входящие, заметки.
Фид — лента «Что я понял и почему»: решения обучения с причинами.
Факт — одна строка с датой в памяти.
Статус — строка вида «(статус ДД.ММ.ГГГГ)»: новая версия заменяет старую.
Портрет — 2–3 предложения вверху профиля, первое, что читает каждый ИИ.
Интент — команда без модели («открой …»), выполняется сразу.
Recovery-ключ — код восстановления забытого пароля шифрования; система показывает его один раз при создании пароля.
