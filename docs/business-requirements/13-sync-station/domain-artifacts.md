# BP-13.4. Артефакты предметной области: синхронизация и станция

## 1. Модель состояний синхронизации и конфликта

```
Цель синхронизации (Google Drive / Dropbox / произвольная папка / станция; активна одна)
 ├─ Не настроена ──настройка пользователем──▶ Настроена
 └─ Настроена ──синхронизация──▶ Синхронизирована (согласованная копия)
      ├─ недоступность цели → повтор через 5 минут; индикатор в трее (FR-09; решение владельца 20.11.2026)
      └─ расхождение версий → Конфликт (см. ниже)

Конфликт (расхождение версий файла между этим компьютером и целью)
 └─ Разрешён трёхсторонним слиянием:
      ├─ остаётся версия этого компьютера (BR-05)
      ├─ чужая версия сохраняется рядом: «<имя> (с другого устройства <дата>)» (BR-05)
      └─ пользователь получает уведомление (BR-05; форма не описана)

Основа слияния — файлы, а не журнал BP-07 (BR-07; раздел 8, основа слияния)
```

| Переход | Откуда → куда | Правило |
|---|---|---|
| Настроить цель | Не настроена → Настроена | BP-13, шаг 1; FR-01, FR-02 |
| Синхронизировать | Настроена → Синхронизирована | BP-13, шаг 1; состав — FR-03, FR-04 |
| Запуск синка | Триггеры: запуск приложения; изменения (не чаще раза в 10 минут); вручную | FR-08; решение владельца 20.11.2026 |
| Недоступность цели | Синхронизирована → повтор через 5 минут | FR-09; индикатор в трее; решение владельца 20.11.2026 |
| Разрешить конфликт | Конфликт → Разрешён | BP-13, шаг 3; FR-05 |
| Сохранить чужую версию | Конфликт → «<имя> (с другого устройства <дата>)» рядом | BP-13, шаг 3; FR-05 |
| Уведомить | Конфликт → уведомление пользователя | BP-13, шаг 3; FR-06 |
| Сохранить шифрование копии | Синхронизирована → копия зашифрована в той же мере | BP-13, шаг 4; FR-07; BP-15 (ссылка) |

## 2. Сущности, состояния и переходы

### 2.1 Цель синхронизации

| Поле | Значение |
|---|---|
| Определение | Место, куда синхронизируется копия памяти: Google Drive, Dropbox, произвольная папка (NAS/USB/другой облачный клиент), станция (раздел 8) |
| Атрибуты | Тип цели (облако / папка / станция); одновременно активна одна цель (решение владельца 20.11.2026) |
| Состояния | Не настроена → Настроена → Синхронизирована |
| Переходы | Настройка (FR-01); синхронизация (FR-01); недоступность цели → повтор через 5 минут, индикатор в трее (FR-09; решение владельца 20.11.2026) |

### 2.2 Станция

| Поле | Значение |
|---|---|
| Определение | Личный сервер владельца с копией памяти; доступ по паролю; роли не вводятся; единственный сервер в системе — станция самого пользователя (раздел 0.2 «Станция», разделы 0, 8; решение владельца 20.11.2026) |
| Атрибуты | Копия памяти (состав — FR-03, FR-04); пароль владельца |
| Состояния | Не настроена → Настроена → Содержит согласованную копию |
| Переходы | Настройка и синхронизация (FR-02); доступ по паролю, роли не вводятся (FR-02; решение владельца 20.11.2026) |

### 2.3 Состав «что уходит»

| Категория | Содержимое | Источник |
|---|---|---|
| Заметки | Без генерируемых сводки/индекса и без локальных сейвов | BP-13, шаг 2; раздел 8 |
| Чаты | Чаты пользователя | BP-13, шаг 2; раздел 8 |
| Правила доступа | Правила доступа клиентов | BP-13, шаг 2; раздел 8 |

### 2.4 Состав «что не уходит никогда»

| Категория | Содержимое | Источник |
|---|---|---|
| Секреты | Ключи, токены | BP-13, шаг 2; раздел 8; хранение — тема 4.1, BP-16 |
| Обучение | Состояние обучения | BP-13, шаг 2; раздел 8 |
| Настройки движка | Настройки движка этого компьютера | BP-13, шаг 2; раздел 8 |

### 2.5 Конфликт

| Поле | Значение |
|---|---|
| Определение | Расхождение версий файла между этим компьютером и целью синхронизации (раздел 8) |
| Состояния | Обнаружен → Разрешён трёхсторонним слиянием |
| Переходы | Слияние: остаётся версия этого компьютера (FR-05); чужая версия — рядом как «<имя> (с другого устройства <дата>)» (FR-05) |
| Примечание | Основа слияния — файлы; журнал BP-07 не участвует (BR-07; раздел 8, основа слияния) |

### 2.6 Уведомление о конфликте

| Поле | Значение |
|---|---|
| Определение | Уведомление пользователя о том, что чужая версия сохранена рядом (раздел 8) |
| Состояния | Отправлено при каждом сохранении чужой версии рядом (FR-06) |
| Примечание | Форма уведомления в источниках не описана |

## 3. Правила процесса

- Цели синка: Google Drive, Dropbox, произвольная папка (NAS/USB/другой облачный клиент), станция;
  перечень закрыт (BP-13, шаг 1; FR-01).
- Уходит только: заметки без генерируемых сводки/индекса и без локальных сейвов; чаты; правила доступа
  клиентов (BP-13, шаг 2; FR-03).
- Не уходит никогда: ключи, токены, состояние обучения, настройки движка этого компьютера
  (BP-13, шаг 2; FR-04).
- Конфликт — трёхстороннее слияние: остаётся версия этого компьютера; чужая — рядом как «<имя>
  (с другого устройства <дата>)»; пользователь уведомляется (BP-13, шаг 3; FR-05, FR-06).
- Основа слияния — файлы, не журнал BP-07 (BR-07; раздел 8, основа слияния).
- Синхронизированная копия зашифрована в той же мере, что и память (BP-13, шаг 4; FR-07; см. BP-15).
- Одновременно активна одна цель синхронизации (решение владельца 20.11.2026).
- Синхронизация запускается при запуске приложения, при изменениях — не чаще раза в 10 минут, и
  вручную (FR-08; решение владельца 20.11.2026).
- При недоступности цели — повтор через 5 минут, индикатор в трее (FR-09; решение владельца 20.11.2026).
- Станция — личный сервер владельца; доступ по паролю; роли не вводятся (FR-02; решение владельца
  20.11.2026).
- Резервные копии дня (снапшот в сейвах) — BP-16, не синхронизация; полная копия папки — на
  усмотрение пользователя или через синхронизацию (раздел 15).
- Человекочитаемые коды в процессе не используются: в источниках не описаны (раздел 6 каталога);
  системные id генерирует система (раздел 1 каталога).

## 4. Словарь терминов процесса

Термины согласованы с разделом 0.2 (термины) human-requirements.txt; определения раздела 0.2 приводятся
дословно, новые термины процесса выводятся из разделов 8, 1.

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | Раздел 0.2 (дословно) |
| Станция | Необязательный собственный сервер пользователя с копией памяти | Раздел 0.2 (дословно) |
| Цель синхронизации | Место, куда синхронизируется копия памяти: Google Drive, Dropbox, произвольная папка (NAS/USB/другой облачный клиент), станция | Раздел 8 |
| Трёхстороннее слияние | Разрешение конфликта: остаётся версия этого компьютера, чужая сохраняется рядом как «<имя> (с другого устройства <дата>)» с уведомлением | Раздел 8 |
| Генерируемые сводка/индекс | Автоматически генерируемые файлы памяти; не синхронизируются | Разделы 8, 1 |
| Локальные сейвы | Локальные сохранения (папка сейвов); не синхронизируются | Разделы 8, 1 |
| Правила доступа клиентов | Правила, какие части памяти и с какими правами видит конкретный ИИ; синхронизируются | Раздел 8; раздел 0.2 «Клиент» |
| Синхронизированная копия | Копия памяти на цели; зашифрована в той же мере, что и память на компьютере | Разделы 1, 8 |
