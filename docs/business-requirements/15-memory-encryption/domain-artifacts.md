# BP-15.4. Артефакты предметной области: шифрование памяти

## 1. Модель состояний шифрования памяти

```
Память создана (создание — BP-01; пока шифрование выключено — читается без приложения, описание памяти)
        │
        ▼
Память открыта (без пароля)
        │  включить пароль — при создании памяти (BP-01) или в настройках (FR-01)
        ▼
Шифрование текст-файлов (FR-02); бинарные и служебные открытые файлы остаются открытыми (FR-04)
        │
        ▼
Память зашифрована (читается и правится только в приложении)
        ├─ запуск без введённого пароля ──► Заблокирована: ошибка блокировки;
        │                                   интерфейс предлагает пароль (FR-05)
        │          ├─ ввод пароля (FR-06; неверный пароль → «пароль не подходит», попытки не ограничены)
        │          ▼
        │      Разблокирована (читается и правится в приложении)
        ├─ копия / синк ──► копия остаётся зашифрованной (FR-03; синк — BP-13, шаг 4)
        ├─ забытый пароль ──► восстановление только по recovery-ключу, показанному один раз (FR-07)
        ├─ смена пароля ──► перешифрование (FR-09)
        └─ удаление пароля ──► полная расшифровка (FR-10)
```

(Решения владельца в диаграмме: неверный пароль — «пароль не подходит» без ограничения попыток;
восстановление — только по recovery-ключу; смена — перешифрование; удаление — полная расшифровка.
Открытым остаётся применение опции Windows вместе с паролем — BP-15.1, «Область вне требований».)

| Переход | Откуда → куда | Правило |
|---|---|---|
| Включить пароль | Память открыта → Память зашифрована | Триггер BP-15; FR-01; при создании памяти — BP-01 |
| Шифрование текст-файлов | Включение пароля → Зашифрована | BP-15, шаг 1; FR-02 |
| Бинарные/PLAIN открыты | — → остаются открытыми; интерфейс предупреждает | BP-15, шаг 2; FR-04; решение владельца |
| Блокировка | Зашифрована → Заблокирована (запуск без пароля) | Триггер BP-15; BP-15, шаг 3; FR-05; краевые состояния |
| Разблокировка | Заблокирована → Разблокирована (ввод пароля) | BP-15, шаг 3; FR-06; результат BP-15 |
| Копия / синк | Зашифрована → Копия зашифрована | BP-15, шаг 1; FR-03; BP-13, шаг 4 |
| Забытый пароль | Заблокирована → Восстановление по recovery-ключу | BP-15, шаг 4; FR-07; решение владельца |
| Смена пароля | Зашифрована → Перешифрована | Решение владельца; FR-09 |
| Удаление пароля | Зашифрована → Полностью расшифрована (открытая память) | Решение владельца; FR-10; описание памяти |
| Опция Windows | — → Отдельный механизм файловой системы | BP-15, шаг 5; FR-08; описание памяти |

## 2. Сущности, состояния и переходы

### 2.1 Пароль шифрования

| Поле | Значение |
|---|---|
| Определение | Пароль пользователя, включающий шифрование памяти; задаётся при создании памяти (BP-01, опционален) или в настройках (описание памяти, онбординг и приложение; триггер BP-15) |
| Атрибуты | Значение пароля; ключевой материал — производный от пароля (решение владельца); recovery-ключ — показывается один раз при создании пароля (решение владельца) |
| Состояния | Не задан → Задан (шифрование включено) → Сменён (перешифрование, FR-09); Удалён (полная расшифровка, FR-10) |
| Переходы | Включить (FR-01); восстановление — только по recovery-ключу (FR-07); сменить (FR-09); удалить (FR-10) |

### 2.2 Память (состояние шифрования)

| Поле | Значение |
|---|---|
| Определение | Папка Markdown пользователя (описание памяти); структура — BP-07 |
| Атрибуты | Признак шифрования: выключено / включено; тип файлов (2.3, 2.4) |
| Состояния | Открыта (без пароля; читается без приложения, описание памяти) → Зашифрована → Заблокирована (запуск без пароля, краевые состояния) / Разблокирована (после ввода пароля); после удаления пароля — Открыта (FR-10) |
| Переходы | Включить пароль (FR-01); запуск без пароля (FR-05); ввод пароля (FR-06); восстановление — по recovery-ключу (FR-07); смена — перешифрование (FR-09); удаление — полная расшифровка (FR-10) |

### 2.3 Текст-файл памяти

| Поле | Значение |
|---|---|
| Определение | Файл памяти текстового формата, шифруемый при включённом пароле (описание памяти) |
| Атрибуты | Тип: .md, .json, .jsonl, .txt, .csv, .tsv, .log, .yml, .yaml, .html, .htm |
| Состояния | Открыт (без пароля) → Зашифрован (AES-256-GCM; читается только в приложении) |
| Переходы | Шифрование (FR-02); копия/синк остаются зашифрованными (FR-03) |

### 2.4 Открытый файл (бинарные и служебные PLAIN)

| Поле | Значение |
|---|---|
| Определение | Бинарные файлы (PDF, картинки, записи) и служебные открытые (PLAIN) файлы — остаются открытыми (описание памяти) |
| Атрибуты | Признак: бинарный / служебный PLAIN |
| Состояния | Открыт всегда (не шифруется) |
| Переходы | —; зафиксировано «только текст-файлы»; интерфейс предупреждает, что бинарные файлы не шифруются (решение владельца; FR-04) |

### 2.5 Опция Windows (файловая система)

| Поле | Значение |
|---|---|
| Определение | Отдельный механизм шифрования средствами файловой системы на Windows (описание памяти) |
| Атрибуты | Доступность на Windows; действует отдельно от пароля |
| Состояния | Доступна → Выбрана пользователем (опция) |
| Переходы | Выбор опции (FR-08); применима ли вместе с паролем — не описано (BP-15.1, «Область вне требований») |

## 3. Правила шифрования

- Шифруются только текст-файлы: .md, .json, .jsonl, .txt, .csv, .tsv, .log, .yml, .yaml, .html, .htm
  (BP-15, шаг 1; описание памяти; BR-02).
- Зашифрованные файлы читаются и правятся только в приложении (BP-15, шаг 1; описание памяти; BR-01).
- Скопированная или синхронизированная копия остаётся зашифрованной в той же мере; синхронизированная
  копия — BP-13, шаг 4 (BP-15, шаг 1; описание памяти, онбординг и приложение; BR-03).
- Бинарные файлы (PDF, картинки, записи) и служебные открытые файлы остаются открытыми — зафиксировано
  «только текст-файлы»; интерфейс предупреждает, что бинарные файлы не шифруются (BP-15, шаг 2; описание памяти;
  решение владельца; BR-04).
- Восстановление забытого пароля — только по recovery-ключу, показанному один раз при создании пароля
  (BP-15, шаг 4; описание памяти; решение владельца; BR-06).
- Ключевой материал шифрования — производный от пароля (решение владельца).
- Смена пароля — в настройках, с перешифрованием; удаление пароля — с полной расшифровкой (решение
  владельца; FR-09, FR-10).
- Неверный пароль — сообщение «пароль не подходит» без ограничения числа попыток (решение владельца;
  FR-06).
- При заблокированной памяти запросы, которым нужна память, отклоняются ошибкой блокировки; интерфейс
  предлагает ввести пароль (BP-15, шаг 3; краевые состояния; BR-05).

## 4. Словарь терминов процесса

Термины согласованы с определениями вводных требований; определения приводятся дословно, новые термины процесса выводятся
из описания памяти, онбординга и приложения, краевых состояний и каталога BP-15.

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | определения (дословно) |
| Пароль шифрования | Пароль, включающий шифрование текст-файлов памяти; задаётся при создании памяти (опционально) или в настройках; ключевой материал — производный от пароля | описание памяти, онбординг и приложение; триггер BP-15; решение владельца |
| Recovery-ключ | Ключ восстановления забытого пароля; показывается один раз при создании пароля | Решение владельца; FR-07 |
| Шифрование памяти | Защита текст-файлов памяти паролем; зашифрованная память читается и правится только в приложении | Назначение BP-15; описание памяти |
| Текст-файлы | Шифруемые форматы: .md, .json, .jsonl, .txt, .csv, .tsv, .log, .yml, .yaml, .html, .htm | описание памяти |
| Бинарные файлы | PDF, картинки, записи — остаются открытыми; интерфейс предупреждает, что они не шифруются | описание памяти; решение владельца |
| PLAIN-файлы | Служебные открытые файлы — не шифруются | описание памяти |
| Заблокированная память | Зашифрованная память при запуске без введённого пароля: запросы, которым нужна память, отклоняются; интерфейс предлагает ввести пароль | краевые состояния; BP-15, шаг 3 |
| Ошибка блокировки | Ответ на запросы, которым нужна память, при не введённом пароле | краевые состояния; BP-15, шаг 3 |
| Разблокировка | Доступ к памяти в приложении после ввода пароля; неверный пароль — сообщение «пароль не подходит» без ограничения попыток | Результат BP-15; FR-06; решение владельца |
| Перешифрование | Повторное шифрование текст-файлов новым паролем при смене пароля | Решение владельца; FR-09 |
| Полная расшифровка | Снятие шифрования со всех текст-файлов при удалении пароля | Решение владельца; FR-10 |
| Опция Windows | Отдельный механизм шифрования средствами файловой системы на Windows | описание памяти; BP-15, шаг 5 |

## 5. Идентификаторы и коды

- Системные id генерирует система (правило каталога, раздел 1).
- Человекочитаемые коды, вводимые пользователем, в BP-15 отсутствуют: в источниках они не описаны
  (раздел 6 каталога). Если такие коды появятся — проверка уникальности по общему правилу каталога
  (раздел 1).
