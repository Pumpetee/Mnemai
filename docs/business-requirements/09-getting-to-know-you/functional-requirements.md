# BP-09.2. Функциональные требования: знакомство и квиз

## 1. Интервью «Знакомство» (BP-09, шаги 1–2)

### FR-01 — Запуск «Знакомства»
Система должна предлагать «Знакомство» (интервью) автоматически при первом знакомстве; повторный запуск —
по кнопке пользователя.
**Приёмка:** интервью предлагается автоматически при первом знакомстве (решение владельца); повторно
пользователь запускает его по кнопке — форма интерфейса или API-команда (FR-07).
(Триггер BP-09; описание обучения; решение владельца)

### FR-02 — Вопросы интервью
Система должна задавать при первом знакомстве вопросы о профиле, правилах, проектах и людях.
**Приёмка:** интервью содержит вопросы по четырём темам: профиль, правила, проекты, люди; конкретный состав
и порядок вопросов не описаны — допущение: вопросы задаются последовательно (BP-09.1, «Область вне требований»).
(BP-09, шаг 1; описание обучения)

### FR-03 — Ответы как обычные факты памяти
Система должна записывать ответы интервью как обычные факты памяти.
**Приёмка:** ответы становятся обычными фактами памяти (профиль, правила, проекты, люди); механика записи —
BP-07; допущение: ответ записывается по мере его получения (BP-09.1, «Область вне требований»).
(BP-09, шаг 2; описание обучения; BP-07)

## 2. Квиз «Насколько Mnemai тебя знает» (BP-09, шаг 3)

### FR-04 — Запуск квиза
Система должна давать запустить квиз «Насколько Mnemai тебя знает».
**Приёмка:** пользователь запускает квиз через форму интерфейса или API-команду (FR-07); повторное
прохождение не описано (BP-09.1, «Область вне требований»).
(Триггер BP-09; описание обучения)

### FR-05 — Факты по одному, от простого к сложному
Система должна показывать в квизе факты памяти по одному, от простого к сложному.
**Приёмка:** в каждый момент показан один факт памяти; факты идут от простого к сложному (решение
владельца); какие факты отбираются — не описано (BP-09.1, «Область вне требований»).
(BP-09, шаг 3; описание обучения; решение владельца)

### FR-06 — Обработка ответов «да / изменилось / нет»
Система должна обрабатывать ответ квиза: «да» — оставить факт, «изменилось» — править, «нет» — удалить.
**Приёмка:** «да» — факт без изменений; «изменилось» — факт правится (механика — BP-07; как задаётся
исправление — не описано, BP-09.1, «Область вне требований»); «нет» — факт удаляется (механика — BP-07).
(BP-09, шаг 3; описание обучения; BP-07)

## 3. Формы запуска (BP-09, шаг 4)

### FR-07 — Форма интерфейса и API-команда
Система должна предоставлять «Знакомство» и квиз как форму интерфейса и как API-команду.
**Приёмка:** оба инструмента доступны через интерфейс и через API-команду.
(BP-09, шаг 4; описание обучения)
