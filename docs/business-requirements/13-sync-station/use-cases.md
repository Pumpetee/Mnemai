# BP-13.3. Сценарии использования: синхронизация и станция

## 0. Сценарий ввода → BP-13

Путь клиента из CLIENT_JOURNEY (раздел 2.8): жизненный цикл приложения «… обновления → синк». Деталей
сценария синка в CLIENT_JOURNEY нет; сценарии строятся по шагам BP-13 каталога. Покрывается UC-01–UC-06.

## UC-01. Подключить облачную цель (Google Drive / Dropbox)

- **Актор:** Пользователь.
- **Предусловие:** память создана (см. BP-01); приложение открыто.
- **Основной поток:**
  1. Пользователь настраивает цель синхронизации — Google Drive или Dropbox. (FR-01; триггер BP-13)
  2. Система синхронизирует память с целью. (FR-01)
  3. На цель уходит только разрешённый состав: заметки без генерируемых сводки/индекса и без локальных
     сейвов, чаты, правила доступа клиентов. (FR-03)
  4. Копия на цели зашифрована в той же мере, что и память на компьютере. (FR-07; см. BP-15)
  5. Далее синк выполняется при запуске приложения и при изменениях — не чаще раза в 10 минут; доступен
     запуск вручную. (FR-08)
- **Альтернативные потоки:**
  - А1 (смена цели): одновременно активна одна цель; для смены пользователь настраивает другую цель
    (FR-01; решение владельца 20.11.2026).
  - А2 (недоступность цели): система повторяет синхронизацию через 5 минут и показывает индикатор в
    трее (FR-09; решение владельца 20.11.2026).
  - А3 (запуск вручную): пользователь запускает синк вручную (FR-08; решение владельца 20.11.2026).
- **Постусловие:** цель настроена; на ней — согласованная зашифрованная копия разрешённого состава.
- **Трассировка:** UC-01 → FR-01, FR-03, FR-07, FR-08, FR-09 → триггер BP-13; шаги 1–2, 4.

## UC-02. Синк с произвольной папкой (NAS/USB/другой облачный клиент)

- **Актор:** Пользователь.
- **Предусловие:** память создана; доступна папка-цель (NAS, USB, папка другого облачного клиента).
- **Основной поток:**
  1. Пользователь настраивает произвольную папку как цель синхронизации. (FR-01; триггер BP-13)
  2. Система синхронизирует память с папкой. (FR-01)
  3. На папку уходит только разрешённый состав (заметки без сводки/индекса и сейвов, чаты, правила
     доступа клиентов). (FR-03)
  4. Копия в папке зашифрована в той же мере, что и память. (FR-07)
- **Альтернативные потоки:**
  - А1 (недоступность папки): папка отключена/недоступна — система повторяет синхронизацию через
    5 минут и показывает индикатор в трее (FR-09; решение владельца 20.11.2026).
  - А2 (сейвы и индекс): пользователь проверяет, что генерируемые сводка/индекс и локальные сейвы в
    папку не попадают (FR-03).
- **Постусловие:** папка-цель содержит согласованную зашифрованную копию разрешённого состава.
- **Трассировка:** UC-02 → FR-01, FR-03, FR-07, FR-09 → триггер BP-13; шаги 1–2, 4.

## UC-03. Конфликт версий — трёхстороннее слияние

- **Актор:** Пользователь.
- **Предусловие:** настроена хотя бы одна цель; один и тот же файл изменён на этом компьютере и на
  другом устройстве (расхождение версий).
- **Основной поток:**
  1. Система обнаруживает расхождение версий. (FR-05; триггер BP-13 — изменение синхронизируемых
     файлов)
  2. Система применяет трёхстороннее слияние: остаётся версия этого компьютера. (FR-05)
  3. Чужая версия сохраняется рядом как «<имя> (с другого устройства <дата>)». (FR-05)
  4. Система уведомляет пользователя о сохранении чужой версии рядом. (FR-06)
- **Альтернативные потоки:**
  - А1 (форма уведомления): вид уведомления в источниках не описан (FR-06; BP-13.1, раздел 7).
  - А2 (основа слияния): слияние идёт по файлам; журнал BP-07 в синхронизации не участвует (FR-05;
    раздел 8, основа слияния).
  - А3 (повтор): повторный конфликт того же файла разрешается по тому же правилу (FR-05; повторные
    конфликты отдельно не описаны).
- **Постусловие:** версия этого компьютера основная; чужая версия сохранена рядом; пользователь
  уведомлён.
- **Трассировка:** UC-03 → FR-05, FR-06 → триггер BP-13; шаг 3.

## UC-04. Станция с копией памяти

- **Актор:** Пользователь, Станция.
- **Предусловие:** у пользователя есть собственный сервер (станция).
- **Основной поток:**
  1. Пользователь настраивает станцию как цель синхронизации. (FR-02; триггер BP-13)
  2. Система синхронизирует память со станцией по правилам состава: только заметки без сводки/индекса
     и сейвов, чаты, правила доступа клиентов. (FR-02, FR-03)
  3. Ключи, токены, состояние обучения и настройки движка на станцию не уходят. (FR-04)
  4. Станция содержит согласованную копию памяти. (FR-02)
- **Альтернативные потоки:**
  - А1 (доступ): доступ к станции — по паролю владельца; роли не вводятся (FR-02; решение владельца
    20.11.2026).
  - А2 (недоступность станции): система повторяет синхронизацию через 5 минут и показывает индикатор в
    трее (FR-09; решение владельца 20.11.2026).
- **Постусловие:** станция содержит согласованную копию памяти; секреты и настройки остались на
  компьютере.
- **Трассировка:** UC-04 → FR-02, FR-03, FR-04, FR-09 → триггер BP-13; шаги 1–2.

## UC-05. Состав синка: что уходит и что не уходит

- **Актор:** Пользователь.
- **Предусловие:** настроена хотя бы одна цель синхронизации.
- **Основной поток:**
  1. Пользователь проверяет, что попало на цель после синка. (FR-03)
  2. На цели — заметки без генерируемых сводки/индекса и без локальных сейвов; чаты; правила доступа
     клиентов. (FR-03)
  3. Ключей, токенов, состояния обучения и настроек движка на цели нет. (FR-04)
- **Альтернативные потоки:**
  - А1 (повтор при другой цели): состав одинаков для всех целей, включая станцию (FR-03, FR-04;
    раздел 8 задаёт один перечень для всех целей).
  - А2 (секреты): хранение и удаление секретов — тема 4.1, BP-16 (ссылка; здесь — только неотправка).
- **Постусловие:** состав на всех целях соответствует правилам «уходит/не уходит».
- **Трассировка:** UC-05 → FR-03, FR-04 → BP-13, шаг 2.

## UC-06. Синк зашифрованной памяти

- **Актор:** Пользователь.
- **Предусловие:** память зашифрована паролем (см. BP-15); настроена цель синхронизации.
- **Основной поток:**
  1. Пользователь включает синхронизацию зашифрованной памяти. (FR-01)
  2. Система синхронизирует память, не ослабляя шифрование. (FR-07)
  3. Копия на цели зашифрована в той же мере, что и память на этом компьютере. (FR-07)
- **Альтернативные потоки:**
  - А1 (заблокированная память): поведение синка при заблокированной (пароль не введён) памяти — по
    правилам BP-15; в BP-13 не описано (см. BP-15; раздел 14).
  - А2 (бинарные файлы): синхронизируются открытыми в той же мере, что и на компьютере — см. BP-15
    (ссылка; раздел 1).
- **Постусловие:** синхронизированная копия зашифрована в той же мере, что и память.
- **Трассировка:** UC-06 → FR-01, FR-07 → BP-13, шаги 1, 4.
