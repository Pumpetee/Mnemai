# BP-11.4. Артефакты предметной области: файлы и документы


## 1. Модель состояний файла в BP-11

```
Пользователь прикрепляет файл / модель просит файловое действие (триггер BP-11)
        │
        ├─ прикрепление (форматы — FR-10; размер ≤ 100 МБ — FR-11) ──► Извлечение текста на компьютере (BP-11, шаг 1; FR-01)
        │        └─ скан/картинка ──► OCR локально (FR-02)   [без локальных движков — допущение; матрица уточняется]
        ├─ файловое действие ──► исполнение по правилам BP-04 (ссылка)
        ▼
Содержимое ──► отбор релевантных частей (BP-11, шаг 2; FR-03)
        │        └─ перед облаком: скрытие секретов (тема 4.1; FR-09) ──► передача модели — BP-02 (ссылка)
        │
Создание/операции: PDF/Word/Excel; слияние/разделение/поворот PDF (BP-11, шаг 3; FR-04, FR-05)
        │        ├─ созданный документ ──► сохранение в папке Saves памяти + показ в чате (FR-12)
        │        └─ запрещённый путь (тема 4.1; FR-07) ──► Отклонено (всегда, ни при каком разрешении)
        ▼
Запись файла ──► зарегистрирована в журнале (BP-11, шаг 4; FR-06) ──► Отменена (через «Историю», BP-07)
        │                                                                [откат файла — допущение]
        ▼
Результат BP-11: содержимое у модели (релевантные части); документ создан или изменён; запись отменяема
```

| Переход | Откуда → куда | Правило |
|---|---|---|
| Прикрепление файла | — → Прикреплено (форматы FR-10; размер ≤ 100 МБ — FR-11) | Триггер BP-11; FR-01, FR-10, FR-11; решение владельца, 20.11.2026 |
| Извлечение текста | Прикреплено → Текст извлечён | BP-11, шаг 1; FR-01 (локально, чат) |
| OCR | Прикреплено → Текст распознан | BP-11, шаг 1; FR-02; платформы — FR-08 |
| Отбор частей | Текст извлечён → Релевантные части | BP-11, шаг 2; FR-03 |
| Скрытие секретов | Релевантные части → Передано модели (без секретов в открытом виде) | Тема 4.1; FR-09; передача — BP-02 |
| Файловое действие | — → Запрошено (BP-04) → Исполняется | Триггер BP-11; BP-04 (ссылка) |
| Создание документа | Исполняется → Документ создан → сохранён в Saves памяти → показан в чате | BP-11, шаг 3; FR-04, FR-12; решение владельца, 20.11.2026 |
| Операция с PDF | Исполняется → PDF изменён | BP-11, шаг 3; FR-05 (параметры — допущение) |
| Запрещённый путь | Запрошено → Отклонено (всегда) | BP-11, шаг 4; FR-07; тема 4.1 |
| Запись в журнал | Документ создан / PDF изменён → Запись зарегистрирована | BP-11, шаг 4; FR-06; механика — BP-07 |
| Отмена | Запись зарегистрирована → Отменена (через «Историю»; откат файла — допущение) | FR-06; BP-07 (тема 4.2) |

## 2. Сущности, состояния и переходы

### 2.1 Вложение

| Поле | Значение |
|---|---|
| Определение | Файл, прикреплённый пользователем в чате; текст извлекается на компьютере (триггер BP-11; BP-11, шаг 1; чат) |
| Атрибуты | Содержимое: текст, скан или картинка (чат); форматы — FR-10; размер ≤ 100 МБ (FR-11); содержимое приложенных файлов уходит в облако как часть запроса (чат «что уходит в облако») |
| Состояния | Прикреплено → Текст извлечён (FR-01) / Текст распознан (OCR, FR-02) → Релевантные части переданы модели (FR-03) |
| Переходы | Прикрепить (FR-01); извлечь (FR-01); распознать (FR-02); отобрать части (FR-03); скрыть секреты (FR-09) |
| Допущение | Где хранятся вложения — не описано (лежат на компьютере пользователя — данные пользователя) (BP-11.1, «Область вне требований») |

### 2.2 Скан / картинка

| Поле | Значение |
|---|---|
| Определение | Изображение, распознаваемое локально (OCR) (BP-11, шаг 1; чат «сканы и картинки распознаются (OCR локально)») |
| Правила | Распознавание — только локально (FR-02); доступно там, где есть локальные движки (FR-08); матрица платформ уточняется (desktop) |
| Состояния | Прикреплено → Распознано (OCR) → Релевантные части у модели |
| Переходы | Распознать (FR-02); без локальных движков — OCR недоступно (FR-08; допущение) |
| Допущение | Передаётся ли распознанный текст модели как текст или вместе с файлом — источники прямо не описывают (BP-11.1, «Область вне требований») |

### 2.3 Документ (PDF/Word/Excel)

| Поле | Значение |
|---|---|
| Определение | Документ, создаваемый системой по запросу: PDF/Word/Excel (BP-11, шаг 3; чат) |
| Атрибуты | Создаётся на компьютере пользователя, сохраняется в папке Saves памяти и показывается в чате (FR-04, FR-12; данные пользователя); запись о создании — в журнале (FR-06) |
| Состояния | Запрошен (BP-04) → Создан → Запись зарегистрирована → Отменена (через «Историю», FR-06) |
| Переходы | Запросить (триггер BP-11; BP-04); создать (FR-04); зарегистрировать (FR-06); отменить (FR-06) |
| Допущение | Детали операций с Word/Excel (из чего создаётся, содержимое, правка) — не описаны (BP-11.1, «Область вне требований») |

### 2.4 Операция с PDF

| Поле | Значение |
|---|---|
| Определение | Операция над PDF: слияние (merge), разделение (split), поворот (BP-11, шаг 3; чат) |
| Правила | Выполняется системой локально (FR-05); запись об изменении — в журнале с отменой (FR-06); запрещённые пути недоступны (FR-07) |
| Состояния | Запрошена (BP-04) → Выполнена → Запись зарегистрирована → Отменена |
| Переходы | Запросить (BP-04); выполнить (FR-05); зарегистрировать (FR-06); отменить (FR-06) |
| Допущение | Параметры операций (порядок и диапазон страниц, угол поворота) — не описаны (BP-11.1, «Область вне требований») |

### 2.5 Запись файла (в журнале)

| Поле | Значение |
|---|---|
| Определение | Регистрируемая в журнале запись о создании или изменении файла; каждая запись отменяется через журнал (BP-11, шаг 4; чат) |
| Атрибуты | Запись создания документа (2.3) или изменения PDF (2.4); отмена — через «Историю» (FR-06) |
| Состояния | Создана → Оставлена / Отменена (файл возвращён к состоянию до записи — допущение) |
| Переходы | Зарегистрировать (FR-06); отменить (FR-06) |
| Примечание | Механика журнала, отмены и «откуда я это знаю» — BP-07 (тема 4.2); BP-11 регистрирует записи файлов, не ведёт журнал |

### 2.6 Извлечённое содержимое

| Поле | Значение |
|---|---|
| Определение | Текст, извлечённый из вложения на компьютере (FR-01) или распознанный OCR (FR-02); модели передаются только релевантные части (BP-11, шаг 2; чат) |
| Правила | Модели — только релевантные части (FR-03); перед облаком — скрытие секретов по теме 4.1 (FR-09); передача модели и показ сэкономленных токенов — BP-02 |
| Состояния | Извлечено/распознано → Релевантные части → Передано модели (секреты скрыты) |
| Переходы | Извлечь (FR-01); распознать (FR-02); отобрать (FR-03); скрыть секреты (FR-09); передать — BP-02 |
| Допущение | Механика отбора релевантных частей источниками не раскрыта (BP-11.1, «Область вне требований») |

### 2.7 Файловое действие

| Поле | Значение |
|---|---|
| Определение | Операция, которую ИИ просит выполнить над файлами: группа «файлы» каталога инструментов (словарь терминов «инструмент/действие»; инструменты) |
| Правила | Запрос, разрешения и исполнение — BP-04; механика операций — BP-11 (2.3, 2.4) |
| Состояния | Запрошено (BP-04) → Исполняется → Выполнено / Отклонено (BP-04, FR-07) |
| Переходы | Запросить (триггер BP-11; BP-04); исполнить (FR-04, FR-05); отклонить (BP-04, FR-07) |
| Допущение | Полный перечень файловых инструментов не приведён (в инструменты — только группа «файлы»; общий пробел с BP-04) |

### 2.8 Deny-list (запрещённые пути)

| Поле | Значение |
|---|---|
| Определение | Жёсткий список запрещённых путей: `.ssh`, `.gnupg`, `.aws`, keyring и секретные хранилища браузеров (ограничения) |
| Правила | Файловые инструменты не могут их читать или писать ни при каком разрешении; команды, в которых эти пути встречаются, отклоняются (ограничения); это чёрный список защиты конкретных секретов, а не песочница — систему он не изолирует (ограничения) |
| Изменения | Любое расширение доступа — только с явного разрешения пользователя и после ревью (ограничения) |
| Применение в BP-11 | FR-07; правила задаёт тема 4.1 (BP-11 применяет, не задаёт); запрет действует при любом ответе на карточку (BP-04) |

## 3. Правила процесса

- **Правило запуска.** Работа с файлами запускается прикреплением файла пользователем или файловым
  действием модели; разрешения и исполнение действий — BP-04 (Триггер BP-11; BR-01).
- **Правило локальности.** Текст извлекается на компьютере; сканы и картинки распознаются локально (OCR)
  (BP-11, шаг 1; BR-02).
- **Правило релевантности.** Модели передаются только релевантные части содержимого; показ экономии —
  BP-02 (BP-11, шаг 2; BR-03).
- **Правило документов.** Система создаёт PDF/Word/Excel и умеет сливать, разделять и поворачивать PDF
  (BP-11, шаг 3; BR-04).
- **Правило журнала.** Каждая запись файлов регистрируется в журнале и отменяется через журнал; механика —
  BP-07 (BP-11, шаг 4; BR-05).
- **Правило deny-list.** Запрещённые пути недоступны ни при каком разрешении; расширение — только с явного
  разрешения пользователя и после ревью (BP-11, шаг 4; BR-06; ограничения; тема 4.1).
- **Правило скрытия секретов.** Содержимое вложений, уходящее в облако, проходит скрытие секретов по
  единым правилам темы 4.1 (BR-07; тема 4.1; приватность).
- **Правило платформ.** OCR доступен там, где есть локальные движки; матрица уточняется (BR-08; desktop;
  тема 4.7).
- **Правило владения.** Файлы создаются и обрабатываются локально; всё созданное пользователем лежит на
  его компьютере — BP-16 (BR-09; ограничения, данные пользователя).
- **Правило форматов.** Поддерживаемые форматы вложений и документов: PDF, Word, Excel, изображения, текст
  (решение владельца, 20.11.2026; FR-10).
- **Правило размера.** Вложения принимаются размером не более 100 МБ (решение владельца, 20.11.2026;
  FR-11).
- **Правило сохранения.** Созданные документы сохраняются в папке Saves памяти и показываются в чате
  (решение владельца, 20.11.2026; FR-12).

## 4. Словарь терминов процесса

Термины согласованы с словарь терминов Этапа 1; определения словарь терминов приводятся дословно, новые термины процесса выводятся
из чат, инструменты, ограничения, данные пользователя и каталога BP-11.

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | словарь терминов (дословно) |
| Инструмент / действие | Операция, которую ИИ просит выполнить: файлы, команды, веб, память, задачи, рабочий стол; файловое действие исполняется по правилам BP-04, механика — BP-11 | словарь терминов (дословно); инструменты |
| Вложение | Файл, прикреплённый пользователем в чате; текст извлекается на компьютере, содержимое (в пределах прав и со скрытыми секретами) уходит модели | чат; BP-11, шаги 1–2 |
| OCR (распознавание сканов и картинок) | Распознавание сканов и картинок локально, на компьютере; доступно там, где есть локальные движки (матрица уточняется) | чат; BP-11, шаг 1; desktop |
| Извлечение текста | Доставание текста из приложенных файлов на компьютере — файл целиком в облако не уходит | чат; BP-11, шаг 1 |
| Релевантные части | Только релевантные части содержимого, которые получает модель; под ответом — сколько токенов сэкономлено (показ — BP-02) | чат; BP-11, шаг 2 |
| Скрытие секретов (redaction) | Замена секретов (карты, пароли, ключи API, токены, телефоны, паспорт, СНИЛС) метками перед облачным запросом и подстановка обратно в ответе | приватность; тема 4.1 |
| Документ (PDF/Word/Excel) | Документ, создаваемый системой по запросу; сохраняется в папке Saves памяти и показывается в чате; каждая запись отменяется через журнал | чат; BP-11, шаг 3; FR-12 |
| Поддерживаемые форматы | Форматы вложений и документов: PDF, Word, Excel, изображения, текст | Решение владельца, 20.11.2026; FR-10 |
| Ограничение размера | Вложения принимаются размером не более 100 МБ | Решение владельца, 20.11.2026; FR-11 |
| Saves (папка памяти) | Папка памяти, куда сохраняются созданные документы; документ также показывается в чате | память; решение владельца, 20.11.2026; FR-12 |
| Операции с PDF | Слияние (merge), разделение (split) и поворот PDF | чат; BP-11, шаг 3 |
| Запись файла и отмена | Каждая запись файлов (создание, изменение) регистрируется в журнале и отменяется через «Историю»; механика — BP-07 | чат; BP-11, шаг 4; тема 4.2 |
| Deny-list (запрещённые пути) | Жёсткий список запрещённых путей (`.ssh`, `.gnupg`, `.aws`, keyring и секретные хранилища браузеров): файловые инструменты не читают и не пишут их ни при каком разрешении; команды с этими путями отклоняются; не песочница | ограничения; тема 4.1 |
| «История» | Место отмены записей: «Память → История», журнал с отменой — см. BP-07 | память, чат; BP-11, шаг 4 |

## 5. Идентификаторы и коды

- Системные id генерирует система (правило каталога, раздел 1).
- Человекочитаемые коды, вводимые пользователем, в BP-11 отсутствуют: в источниках они не описаны
  (раздел 6 каталога). Если такие коды появятся (например, имя создаваемого документа) — проверка
  уникальности по общему правилу каталога (раздел 1).
