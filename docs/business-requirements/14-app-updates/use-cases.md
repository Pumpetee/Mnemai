# BP-14.3. Сценарии использования: обновления приложения

Цепочка прослеживаемости: сценарий ввода → BP-14 (каталог бизнес-процессов) → BP-14.1…4 (эта папка). Каждый UC трассирован «UC → FR → BP-14 шаг»; трассировка включает FR альтернативных потоков и триггер BP-14.

## 0. Сценарий ввода → BP-14

Путь клиента, шаг 2.8: окно/трей → закрыть/скрыть → автозапуск → обновления → синк.
Шаг «обновления» покрывается UC-01–UC-04; закрытие/трей и автозапуск — тема 4.7 (см. BP-12), синк —
BP-13. Сценарий согласуется с раздел «Desktop и жизненный цикл»; расхождений не найдено (BP-14.1).

## UC-01. Новая версия найдена (тихая проверка и кнопка Update)

- **Актор:** Mnemai (проверка), Пользователь (нажатие кнопки).
- **Предусловие:** приложение запущено и работает на текущей версии.
- **Основной поток:**
  1. Приложение запускается — срабатывает проверка релизов. (FR-01; триггер BP-14)
  2. Система проверяет наличие новых релизов из GitHub-релизов по стабильному каналу. (FR-01, FR-09)
  3. Новая версия найдена — система показывает кнопку Update. (FR-02)
  4. Пользователь нажимает кнопку Update; система начинает установку. (FR-03)
  5. Установка выполняется по правилам ОС — UC-02.
- **Альтернативные потоки:**
  - А1 (обновлений нет): новая версия не найдена — кнопка Update не показывается, работа продолжается
    (FR-02).
  - А2 (отказ): пользователь не нажимает кнопку — приложение продолжает работать на текущей версии;
    кнопка остаётся доступной (FR-02; допущение: срок действия предложения не описан).
  - А3 (канал): проверка выполняется по стабильному каналу; бета-каналы не предусмотрены (FR-09).
- **Постусловие:** новая версия найдена и предложена через кнопку Update; установка запущена (или
  отложена пользователем).
- **Трассировка:** UC-01 → FR-01, FR-02, FR-03, FR-09 → триггер BP-14; BP-14, шаг 1.

## UC-02. Обновление применено (установка по ОС)

- **Актор:** Пользователь (инициирует и завершает установку), Mnemai (исполняет).
- **Предусловие:** новая версия найдена; пользователь нажал кнопку Update (UC-01).
- **Основной поток:**
  1. Система проверяет целостность обновления по контрольной сумме. (FR-07; триггер BP-14 — нажатие
     кнопки Update, FR-03)
  2. Контрольная сумма совпала; система устанавливает обновление по ОС:
     - Windows — при выходе из приложения (FR-04; выход — по правилам темы 4.7, см. BP-12);
     - Linux — замена установочного файла и перезапуск (FR-05);
     - macOS — открытие образа установки и инструкция по установке в окне (FR-06).
  3. Приложение работает на новой версии.
- **Альтернативные потоки:**
  - А1 (несовпадение суммы): контрольная сумма не совпала — обновление не применяется — UC-03 (FR-08).
  - А2 (сбой установки): установка завершилась сбоем — обновление не применяется — UC-04 (FR-08).
  - А3 (macOS): после открытия образа пользователь действует по инструкции в окне (FR-06).
- **Постусловие:** установлена новая версия (результат BP-14) — или обновление безопасно не применено
  (UC-03, UC-04).
- **Трассировка:** UC-02 → FR-03, FR-04, FR-05, FR-06, FR-07, FR-08 → триггер BP-14; BP-14, шаги 2–3;
  тема 4.7 — ссылка.

## UC-03. Контрольная сумма не совпала — обновление не применяется

- **Актор:** Mnemai.
- **Предусловие:** новая версия найдена; установка начата (UC-02).
- **Основной поток:**
  1. Система проверяет целостность обновления по контрольной сумме. (FR-07)
  2. Контрольная сумма не совпала. (FR-07)
  3. Система не применяет обновление. (FR-08)
  4. Приложение продолжает работать на текущей версии. (FR-08)
- **Альтернативные потоки:**
  - А1 (запасной источник): основной источник (метаданные релиза) недоступен — система использует
    запасной файл контрольной суммы (FR-07).
  - А2 (повтор): повторная попытка установки — по кнопке Update (FR-03).
- **Постусловие:** обновление не применено; приложение на текущей версии.
- **Трассировка:** UC-03 → FR-03, FR-07, FR-08 → BP-14, шаг 3.

## UC-04. Сбой установки — обновление не применяется

- **Актор:** Mnemai, Пользователь (видит результат).
- **Предусловие:** новая версия найдена; установка начата (UC-02).
- **Основной поток:**
  1. Система устанавливает обновление по правилам ОС (FR-04, FR-05, FR-06).
  2. Установка завершается сбоем. (FR-08)
  3. Система не применяет обновление. (FR-08)
  4. Приложение продолжает работать на текущей версии. (FR-08)
- **Альтернативные потоки:**
  - А1 (повтор): повторная попытка установки — по кнопке Update (FR-03).
  - А2 (сбой проверки): при сбое самой проверки релизов цикл пропускается без установки (FR-08).
  - А3 (откат): возврат на прежнюю версию — переустановкой приложения (решение владельца).
- **Постусловие:** обновление не применено; приложение на текущей версии; данные пользователя не
  затронуты (допущение: последствия сбоя для текущей версии не описаны).
- **Трассировка:** UC-04 → FR-03, FR-04, FR-05, FR-06, FR-08 → BP-14, шаги 2–3.
