## 2. Сущности, состояния и переходы

### 2.1 Вопрос интервью

| Поле | Значение |
|---|---|
| Определение | Вопрос, который система задаёт при первом знакомстве (описание обучения) |
| Атрибуты | Тема: профиль, правила, проекты, люди (BP-09, шаг 1); формулировка вопроса (конкретный состав не описан — BP-09.1, «Область вне требований») |
| Состояния | Задан → Отвечен |
| Переходы | Задать (FR-02); порядок вопросов — допущение (BP-09.1, «Область вне требований») |

### 2.2 Ответ интервью

| Поле | Значение |
|---|---|
| Определение | Ответ пользователя на вопрос интервью; становится обычным фактом памяти (описание обучения) |
| Атрибуты | Текст ответа; тема вопроса (2.1); факт памяти, в который записывается |
| Состояния | Дан → Записан как обычный факт |
| Переходы | Запись (FR-03); запись по мере ответа — допущение (BP-09.1, «Область вне требований»); механика — BP-07 |

### 2.3 Квиз

| Поле | Значение |
|---|---|
| Определение | «Насколько Mnemai тебя знает»: показывает факты памяти по одному; ответы правят память (описание обучения) |
| Атрибуты | Показываемые факты — по одному, от простого к сложному (решение владельца); отбор фактов не описан (BP-09.1, «Область вне требований»); ответ пользователя (2.4) |
| Состояния | Запущен → Факт показан → Ответ обработан |
| Переходы | Запуск (FR-04); показ по одному (FR-05); обработка ответа (FR-06) |

### 2.4 Ответ квиза

| Поле | Значение |
|---|---|
| Определение | «да / изменилось / нет»: «да» оставляет факт, «изменилось» правит, «нет» удаляет (BP-09, шаг 3; описание обучения) |
| Атрибуты | Вариант: да / изменилось / нет; факт, к которому относится |
| Состояния | Выбран → Применён к факту |
| Переходы | Применение (FR-06); правка и удаление — BP-07; как задаётся исправление при «изменилось» — не описано (BP-09.1, «Область вне требований») |

## 3. Правила записи ответов как фактов

- Ответы интервью записываются как обычные факты памяти (BP-09, шаг 2; FR-03; BR-03).
- Механика записи, правки, удаления, журнала и отмены — BP-07 (факт одной строкой с датой, журнал
  чтений/записей, отмена, «откуда я это знаю» — см. BP-07, описание памяти); здесь не дублируется.
- Обучение в процесс не входит: ответы не проходят конвейер обучения (границы BP-09; конвейер — BP-08).
- Какие факты памяти показываются в квизе — не описано (BP-09.1, «Область вне требований»); порядок
  задан решением владельца — от простого к сложному.

## 4. Словарь терминов процесса

Термины согласованы с определениями вводных требований; определения приводятся дословно, новые термины процесса выводятся
из описания обучения и каталога BP-09.

| Термин | Определение | Источник |
|---|---|---|
| Пользователь (владелец) | Человек, чья это память и компьютер. В массовом продукте — любой человек | определения (дословно) |
| Скоуп | Раздел памяти: профиль, правила, проекты, карточки, люди, решения, входящие, заметки | определения (дословно) |
| Факт | Одна строка с датой в Inbox, карточке или журнале проекта; механика — BP-07 | описание памяти; BP-07 |
| «Знакомство» (интервью) | Вопросы при первом знакомстве; ответы становятся обычными фактами памяти (профиль, правила, проекты, люди); предлагается автоматически при первом знакомстве, повторно — по кнопке | описание обучения; BP-09, шаги 1–2; решение владельца |
| Квиз «Насколько Mnemai тебя знает» | Показывает факты памяти по одному, от простого к сложному; ответ «да / изменилось / нет» правит память | описание обучения; BP-09, шаг 3; решение владельца |
| Ответ квиза | «да» — оставить факт; «изменилось» — править; «нет» — удалить | BP-09, шаг 3; описание обучения |
| Обычный факт памяти | Факт, записанный как любая другая запись памяти — в отличие от записей обучения (BP-08) | описание обучения |
| Форма интерфейса / API-команда | Способы запуска «Знакомства» и квиза | BP-09, шаг 4; описание обучения |
