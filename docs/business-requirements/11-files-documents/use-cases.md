# BP-11.3. Сценарии использования: файлы и документы


## 0. Сценарий ввода → BP-11

Отдельного пути «файлы и документы» в CLIENT_JOURNEY нет; BP-11 достигается двумя путями: прикрепление
файла в чате (BP-02) и файловое действие модели (BP-04). ARCHITECTURE.ru, раздел «Одно сообщение в чате», шаг 3,
описывает вложения: «текст достаётся на компьютере; сканы и картинки — файлом, где модель их читает» —
расхождение с каталогом BP-11 (только релевантные части, OCR закреплён за BP-11) отмечено в BP-11.1.
Сценарий покрывается UC-01–UC-07; решения владельца (20.11.2026) — UC-08.

## UC-01. Прикрепить файл в чате

- **Актор:** Пользователь (прикрепляет), Система (извлекает, отбирает), ИИ (получает содержимое).
- **Предусловие:** идёт разговор в чате (BP-02).
- **Основной поток:**
  1. Пользователь прикрепляет файл в чате. (Триггер BP-11; FR-01)
  2. Система извлекает текст из файла на компьютере. (FR-01)
  3. Система отбирает релевантные части содержимого. (FR-03)
  4. Перед отправкой в облако секреты заменяются метками. (FR-09)
  5. Содержимое передаётся модели по правилам BP-02; ответ продолжается. (FR-03; BP-02)
- **Альтернативные потоки:**
  - А1 (скан/картинка): система распознаёт файл локально (OCR) — UC-02 (FR-02).
  - А2 (платформа без движков OCR): OCR недоступно — допущение; матрица уточняется (FR-08).
  - А3 (формат вне перечня): форматы вне перечня PDF, Word, Excel, изображения, текст не поддерживаются
    (FR-10).
  - А4 (офлайн): облачная передача недоступна — BP-02, шаг 8; извлечение текста локально продолжает
    работать (FR-01; крайние состояния; UC-07).
  - А5 (журнал исходящих): каждый облачный запрос логируется — BP-02, BP-16 (тема 4.1 — ссылка).
  - А6 (слишком большой файл): вложение больше 100 МБ не принимается (FR-11).
- **Постусловие:** текст извлечён локально; модели переданы только релевантные части; секреты скрыты.
- **Трассировка:** UC-01 → FR-01, FR-02, FR-03, FR-08, FR-09, FR-10, FR-11 → триггер BP-11; границы BP-11;
  BP-11, шаги 1–2; BP-02; тема 4.1; решения владельца (20.11.2026).

## UC-02. Распознать скан или картинку (OCR локально)

- **Актор:** Пользователь (прикрепляет), Система (распознаёт), ИИ (получает содержимое).
- **Предусловие:** в чат прикреплён скан или картинка (UC-01).
- **Основной поток:**
  1. Система распознаёт скан или картинку локально (OCR). (FR-02)
  2. Распознанный текст — содержимое файла: модели передаются релевантные части (FR-03; допущение:
     распознанный текст передаётся модели как текст — источники прямо не описывают, BP-11.1, «Область вне
     требований»).
  3. Перед отправкой в облако секреты заменяются метками. (FR-09)
- **Альтернативные потоки:**
  - А1 (нет локальных движков): OCR недоступно — допущение; матрица платформ уточняется (FR-08).
  - А2 (секреты в скане): скрытие секретов перед облаком действует как для любого содержимого (FR-09).
- **Постусловие:** текст распознан локально; в облако ушли только релевантные части со скрытыми секретами.
- **Трассировка:** UC-02 → FR-02, FR-03, FR-08, FR-09 → триггер BP-11; границы BP-11; BP-11, шаги 1–2;
  тема 4.1; тема 4.7.

## UC-03. Создать документ (PDF/Word/Excel)

- **Актор:** ИИ (запрашивает), Пользователь (подтверждает), Система (создаёт).
- **Предусловие:** модель в чате просит создать документ; разрешение — по правилам BP-04.
- **Основной поток:**
  1. Модель запрашивает создание документа. (Триггер BP-11; BP-04)
  2. Система создаёт документ на компьютере пользователя. (FR-04)
  3. Запись файла регистрируется в журнале. (FR-06)
  4. Документ сохраняется в папке Saves памяти и показывается в чате (FR-12); результат возвращён модели
     (BP-04).
- **Альтернативные потоки:**
  - А1 (отклонено): «нет» на карточке разрешения — BP-04 (ссылка).
  - А2 (запрещённый путь): запись в запрещённый путь невозможна — UC-06 (FR-07).
  - А3 (отмена): пользователь отменяет запись через «Историю» — UC-05 (FR-06).
- **Постусловие:** документ создан; запись в журнале и отменяема.
- **Трассировка:** UC-03 → FR-04, FR-06, FR-07, FR-12 → триггер BP-11; BP-11, шаги 3–4; результат BP-11;
  BP-04 (ссылка); решение владельца (20.11.2026).

## UC-04. Операции с PDF: слияние, разделение, поворот

- **Актор:** ИИ (запрашивает), Пользователь (подтверждает), Система (выполняет операцию).
- **Предусловие:** модель просит операцию с PDF; разрешение — по правилам BP-04.
- **Основной поток:**
  1. Модель запрашивает слияние, разделение или поворот PDF. (Триггер BP-11; BP-04)
  2. Система выполняет операцию над PDF. (FR-05)
  3. Запись файла регистрируется в журнале. (FR-06)
  4. Результат возвращён модели (BP-04).
- **Альтернативные потоки:**
  - А1 (параметры операции): порядок страниц, диапазон, угол поворота — не описаны (BP-11.1, «Область вне
    требований»).
  - А2 (отмена): пользователь отменяет запись через «Историю» — UC-05 (FR-06).
  - А3 (запрещённый путь): операция затрагивает запрещённый путь — UC-06 (FR-07).
- **Постусловие:** операция выполнена; запись в журнале и отменяема.
- **Трассировка:** UC-04 → FR-05, FR-06, FR-07 → триггер BP-11; BP-11, шаги 3–4; результат BP-11; BP-04
  (ссылка).

## UC-05. Отмена записи файла

- **Актор:** Пользователь (отменяет), Система.
- **Предусловие:** запись файла сделана (UC-03, UC-04) и есть в журнале.
- **Основной поток:**
  1. Пользователь открывает «Историю». (BP-07)
  2. Пользователь отменяет запись файла. (FR-06)
  3. Файл возвращается к состоянию до записи (допущение: откат файла — механика BP-07, тема 4.2;
     источники прямо не описывают, BP-11.1, «Область вне требований»).
- **Альтернативные потоки:**
  - А1 (механика журнала): журнал, отмена, «откуда я это знаю» — BP-07 (тема 4.2) — ссылка.
- **Постусловие:** запись отменена; файл в состоянии до записи (допущение).
- **Трассировка:** UC-05 → FR-06 → BP-11, шаг 4; результат BP-11; тема 4.2; BP-07.

## UC-06. Запрещённый путь (deny-list)

- **Актор:** ИИ (запрашивает), Система (отклоняет), Пользователь (не может разрешить).
- **Предусловие:** модель просит файловое действие или команду, затрагивающие запрещённые пути секретов.
- **Основной поток:**
  1. Модель запрашивает файловое действие с запрещённым путём.
  2. Система отклоняет: файловые инструменты не читают и не пишут эти пути, команды с этими путями
     отклоняются — ни при каком разрешении. (FR-07)
  3. Отказ возвращён модели (BP-04 — ссылка).
- **Альтернативные потоки:**
  - А1 («да»): даже «да» пользователя на карточке не открывает доступ — запрет действует при любом
    разрешении (FR-07).
  - А2 (расширение): расширение доступа — только с явного разрешения пользователя и после ревью; deny-list
    остаётся чёрным списком защиты секретов, а не песочницей (ограничения; тема 4.1).
- **Постусловие:** действие не выполнено; секреты не затронуты.
- **Трассировка:** UC-06 → FR-07 → BP-11, шаг 4; тема 4.1; инструменты, ограничения.

## UC-07. Файловые операции офлайн

- **Актор:** ИИ (локальная модель — запрашивает), Пользователь, Система.
- **Предусловие:** нет сети (офлайн); работает локальная модель (BP-02, шаг 8; крайние состояния).
- **Основной поток:**
  1. Локальная модель просит файловое действие (BP-04). (Триггер BP-11)
  2. Система выполняет локальные операции: извлечение текста, OCR, создание документов, операции с PDF.
     (FR-01, FR-02, FR-04, FR-05)
  3. Записи файлов регистрируются в журнале с отменой. (FR-06)
- **Альтернативные потоки:**
  - А1 (облако недоступно): передача содержимого облачным провайдерам недоступна — BP-02, шаг 8 (ссылка).
  - А2 (нет движков OCR): OCR недоступно — допущение (FR-08).
- **Постусловие:** файловые операции выполнены локально; записи отменяемы.
- **Трассировка:** UC-07 → FR-01, FR-02, FR-04, FR-05, FR-06, FR-08 → триггер BP-11; границы BP-11;
  BP-11, шаги 1, 3–4; крайние состояния; BP-02 (ссылка).

## UC-08. Созданный документ — в Saves памяти и в чате

- **Актор:** ИИ (запрашивает), Пользователь (подтверждает и видит документ), Система.
- **Предусловие:** модель просит создать документ; разрешение — по правилам BP-04.
- **Основной поток:**
  1. Модель запрашивает создание документа. (Триггер BP-11; BP-04)
  2. Система создаёт документ. (FR-04)
  3. Система сохраняет документ в папке Saves памяти. (FR-12)
  4. Система показывает документ в чате. (FR-12)
  5. Запись файла регистрируется в журнале. (FR-06)
- **Альтернативные потоки:**
  - А1 (отмена): пользователь отменяет запись через «Историю» — UC-05 (FR-06).
  - А2 (запрещённый путь): сохранение в запрещённый путь невозможно — UC-06 (FR-07).
- **Постусловие:** документ создан, сохранён в папке Saves памяти, показан в чате; запись отменяема.
- **Трассировка:** UC-08 → FR-04, FR-06, FR-07, FR-12 → триггер BP-11; BP-11, шаги 3–4; результат BP-11;
  решение владельца (20.11.2026).
